# 研究任务中的段落翻译（0.20.0）

研究任务可以直接执行明确选定的正文段落翻译，和原文证据、写作框架、流程图等产物一起保存。最多4段，中英两种目标语言；不是自动全文翻译或PDF译文重排。

## 从页面使用

1. 打开“研究任务”，输入含“翻译”的目标，或在“手动选择输出”中勾选“段落翻译”。
2. 在右侧勾选实际需要的文献。翻译区域只列出这些文献；同作品最终版本选择仍受既有规则约束。
3. 在“待译文献”选择一篇，填写PDF页码，点击“读取本页段落”。这里只读取本地这一页。
4. 勾选正文段落，可跨页、跨文献，合计最多4段。列表保留完整原文；图表、公式与书目不加入该步骤。
5. 选择中文或英文，可填术语表，每行`原词=译法`。例如`Transfer Learning=迁移学习`。
6. 点击“生成执行计划”，检查“确认翻译范围”中的版本、页码和原文，再决定是否开始执行。
7. 在步骤列表查看“翻译段落N”。桌面原译并排，手机上下排列；“PDF第N页”返回原解析版本和段落位置。任务包包含每段原译Markdown与完整来源JSON。

“执行时允许模型生成”默认关闭。关闭且没有匹配缓存时，结果明确显示“尚未生成译文”，保留原文，不把复制的原文当作翻译。已有同一来源、目标语言、术语表和模型身份的缓存时可直接复用，不增加模型请求。需要新译文时再允许模型生成。

纯翻译任务的证据步骤直接保留所选段落，不额外请求问答生成。混合问答/综述等任务仍使用相应工具；允许模型时，其调用也计入同一执行预算。写作框架继续使用原论文证据，译文候选不会自动升级为论文事实或学术结论。

## 预算、暂停和失败

每个段落是一个独立工具步骤，每次未命中缓存的尝试最多发出一次翻译请求，预留3500输出token。实际用量按服务商响应记录；3500是上限预留，不是实耗。规划请求另计，连接检查也不会变成翻译预算的一部分。

模型预算不足时，本段保持待执行，任务进入“达到预算”，不伪装成翻译完成。显式调整预算后继续，已完成段落不重译。暂停/取消在段落边界生效；总活动时间仍为步骤边界检查，不是强制中断单次请求。

HTTP或内容保护校验失败时，按任务原有恢复策略保留失败尝试，允许时插入“保留原文并继续本地流程”；该结果没有译文，并关闭任务后续模型调用。达到调整上限或策略要求停止时不继续。原文失效、来源变化和未知工具错误不能用恢复绕过。请求中断可能已经计费，不自动追加付费重试。

缓存沿用`translation-v1`，绑定文献、ParseRun、块ID、原文、目标语言、术语表和模型身份。执行前后检查原文；任务还固定翻译模型身份。改变模型配置后请新建任务，旧历史仍保留原结果。缓存不是语义质量认证。
