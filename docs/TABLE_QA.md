# 固定版本的表格问答与手工稿对照

适用本机0.17.0。入口：**文献与阅读 → 打开PDF → 对应页 → 表格**。先按[表格重建说明](TABLE_REFINEMENT.md)保存来源，再加入当前问题。原生单元格保持“候选、未核验”；手工稿独立展示，不会因为保存或引用就变成论文事实。

## 从页面操作

1. 选择“已有表格候选”，点击“按表头重建行列”；没有默认候选时，明确输入区域、表头下界与需要的列界。对照原图核对范围、表头及待归列文字。
2. 已有来源可以从“本页表格来源历史”打开。需要使用哪份手工稿，就在“表格修订历史”选中该版。编辑后先另存；未保存的改动不能加入问答。
3. 点击“整表加入问答核对”，或选一个单元格后点击“仅所选行加入问答”。再次添加同一来源、同一修订的另一行，会合并行范围。界面的“文字行”从1计数，不含另存的表头。
4. 右侧输入区会显示来源、页码、行范围和手工稿提示。默认勾选“仅检索所选表格”；取消后会同时检索原正文。同一文献只使用一个固定解析版本。加入同篇另一解析版本的来源时，旧版本的已选来源会移除。
5. 写明要核对的模型、训练条件、指标与列名。关闭“启用模型回答”可只检索，不调用服务商。开启后，生成也只接收原生候选和正文；没有可用原生证据时不会因为存在手工稿而调用模型。
6. 原文证据卡显示原生行上下文、列名和具体值。点击“查看原文”定位该解析版本的原页单元格；相邻数值需要逐个核对，不能只看同页有高亮就确认答案。
7. 手工变化在“手工稿对照 · 未核验”中显示原候选、修订值、列名变化及说明。点击“核对原页位置”只高亮需要复核的原区域；“打开此版完整来源”导出这份确切修订。
8. 点击来源旁的“移除”可退出当前问题。此操作不会发送输入中的问题。切换文献后，范围外的已选来源仍显示，明确标为不参与当前检索，可手工移除。

已选来源只保存在当前页面会话；刷新页面后需要重新添加。已保存的回答记录会保留当时的确切来源和修订，不会自动改用新稿。原表格、修订及问答仍保留各自历史。

## 两种内容分别怎样使用

| 内容 | 可进入模型 | 可作本次原生证据 | 展示方式 |
|---|---|---|---|
| 有原生词引用的原始单元格、原表头和行条件 | 是 | 是，但仍为未核验候选 | 原文证据、页码与格坐标 |
| 手工修改或补录的单元格 | 否 | 否 | 原候选与手工稿对照 |
| 手工列名与修订备注 | 否 | 否 | 独立对照及导出 |
| 覆盖格、空格、缺少原生词引用的位置 | 否 | 否 | 保留缺失，或在手工对照中提示 |

即使选中了某份修订，模型使用的仍是原生候选；手工值不会替换模型输入。原生候选自身也可能归列错误，行名和表头锚点用于复核，并不证明语义正确。仅有手工值的两行可以返回两份对照，同时保持0条原文证据、0条生成陈述。

表格生成陈述必须只引用一个真实候选格，保留该格的字面值并通过已有数字检查。服务端用原生的行条件、列名和值重新组织显示文本，防止模型把相同数字说成另一条件的结果。状态为`table_candidate`，`semantic_verified=false`。当前不自动计算差值、平均数、显著性或胜负关系。

## 来源、接口与限制

`POST /api/ask`增加以下可选项；不提供表格选择时，普通问答路径保持原行为。

| 字段 | 含义 |
|---|---|
| `table_sources` | 最多6份已保存来源；每项有`source_id`、可选确切`revision_id` |
| `row_indices` | 来源项中的可选数组；严格整数、从0计数、最多12个不同有效行；省略表示整表 |
| `table_only` | 仅检索所选原生表格；必须同时有有效来源 |
| `use_model` | 是否允许本次生成；无可用原生证据仍跳过生成 |
| 响应`table_context` | 当时的来源、修订、行范围、文件与解析版本绑定 |
| 响应`table_drafts` | 独立手工对照，`sent_to_model=false`，不属于事实证据ID集合 |

同一来源不能重复提交，同篇不能混用多个ParseRun；跨文献范围、错误修订归属、重复/越界行会被拒绝。表格来源绑定文件哈希、ParseRun、页码、区域与原生词坐标。生成后和读取历史时重新检查来源；文件/历史版本已删除、来源缺失或格内容发生不一致时，相关证据和陈述会失效。

表格检索采用当前所选来源内的词项排名，不写入全库索引，也不执行表格Dense检索。只选表格时不会触发全文或语义索引构建；混合模式按固定版本组合正文与表格。没有自动将全部历史表格加入所有问题。

尚未覆盖扫描表格OCR、可靠的无框复杂合并关系、跨页表格、所有指标的语义推理或统一的表格质量验收。当前限制还包括最多6份来源、每份所选行最多12行，以及原表重建的150行/40列/2000格上限。独立人工学术复核仍待完成。
