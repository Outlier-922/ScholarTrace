# 当前开发目标与完成口径

按用户明确要求，当前目标是把科研助手作品本身完善好。GitHub/Gitee上传、演示视频、最终展示PDF、公网发布和参赛身份材料由用户在作品完成后自行处理，不计入本轮产品未完成项，也不作为开发阻塞原因。

产品完成看六模块的实际功能和官方样例：文献解析、可靠问答、阅读翻译、发现推荐、图谱综述及写作绘图可用，已知关键功能缺失得到处理，代表性结果可以回查原文或数据。自主工具循环及其预算、校验、无模型原文语义也属于产品范围。

产品验收默认运行 `scripts/check_acceptance.py`，返回 `product_ready` 和 `unfinished_product_items`。`--require-ready` 默认只检查产品功能。展示发布事项在数据中标记 `completion_scope=user_handoff`；如用户以后需要核对官方提交材料，可显式加 `--scope submission`，不改变当前开发任务。

不能把自动测试通过等同于科研结论全部正确，也不能用不存在的“所有论文100%正确”标准无限延长开发。按可复查的具体场景关闭缺口；事实错误、条件混淆和缺失的必要功能须继续修复。
