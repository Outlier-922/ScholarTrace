## 实现范围

`answer_fields.py`提供固定字段注册表，不含论文身份或预期实验数值。逐文逐字段补检索最多12次本地查询，每次至多3个命中；最终证据受请求k限制，至多12。按候选词提示覆盖分配，不是语义证明。识别字段最多8类；限制子句做通用否定过滤，复杂表达仍可能漏识别。

生成仍为一次模型请求、输出预留1600 token。结构化字段行最多20条，限定所问字段、实际document_id和同篇来源。来源、数字和明显公式残片检查后，按论文/字段展示；冲突、未完成、候选不足及来源删除分别标记。旧响应兼容，但不会信任旧格式附带的伪造覆盖信息。研究任务的证据工具复用此检索和格式，保留预算与固定解析快照。

前端显示“已识别字段的覆盖”，每字段提供原文按钮；明确提示可能漏项且候选回答需核对事实和条件。未实现完整NLI、数学表达式恢复或通用自然语言需求解析。
