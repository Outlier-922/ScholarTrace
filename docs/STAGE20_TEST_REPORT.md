# 第二十阶段实测：固定表格来源与问答（0.17.0）

日期2026-10-29。本轮把上一阶段保存的表格接到当前问题：整表/所选行、确切ParseRun与修订、原生单元格证据、独立手工对照及原页定位。没有把手工修订升级成论文事实，没有宣称完整表格语义或整体作品完成。

## 本轮行为

- 当前问题显式选择来源；同篇固定单一解析版本，所选行合并有界。普通问答未选择表格时保留原提示与载荷。
- 原生候选按格检索，包含原表头、行条件、词引用和坐标。表格专用模式跳过全库及Dense检索；混合模式组合正文与表格。
- 手工值、列名、备注作为`table_drafts`独立对照，既不进入模型，也不能作为事实证据ID。仅有手工值时保持证据不足并跳过生成。
- 表格陈述只接受单个真实格和字面原值，服务端以原行条件/原列名/原值重新组织文本，保持`table_candidate`、`semantic_verified=false`。
- 问答和历史读取重新校验不可变来源；源文献/解析版本删除或格元数据不一致时，移除相关事实候选。新修订不会改写旧回答。

## 限制与交付状态

模型没有接受手工修订值，因此不能声称已采用人工更正后的论文事实。原生候选也可能切列/归行错误；服务器重组文本和有效坐标不能保证学术语义。缺失行不推测填充，不自动计算差值或比较结论，不构建持久全库表格索引。复杂无框表、扫描表、跨页表和独立语义复核仍待完成。

总验收保持`submission_ready=false`，仍有20个必要项未通过；M2-QUALITY仍为部分实现。公网、评审仓库访问、最终技术PDF、正式MP4、报名信息及其他功能质量缺口继续保留。健康能力中的`pinned_table_qa=true`只表示本轮链路可用，`semantic_tables=false`保持不变。
