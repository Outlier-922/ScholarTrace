## 变更与边界

- 新增持久化全文交接：固定书目原快照、检索/原任务ID、文档ID、PDF SHA-256及ParseRun。下载入库返回交接；已有本地全文可明确选择并确认关联，重复确认复用同一记录。
- arXiv匹配确切标识符与版本，Crossref只列出标题字面一致的本地候选；仍需核对标题/作者/版本。客户端勾选属于明确确认，既不称自动身份认证，也不称独立人工质量评审。
- “后续研究”可重新打开、显示等待/失败/就绪；解析未就绪、缺失内容、来源删除或文件变化时不允许创建任务。
- 研究任务接受显式ParseRun与handoff_id，规划模型前校验范围；强制包含交接全文，不被较新同作品文档替换。即使后来重新解析，旧交接仍使用原来已完成的历史版本。执行前再次核对文件哈希和交接记录。
- 新任务有独立计划和预算；默认规则规划、仅原文证据、模型关闭。父任务不变。CSV、翻译、比较等仍走既有显式参数与权限；书目不进入全文证据。
- 任务Markdown/JSON保留交接链，ZIP有单独handoff.json。
