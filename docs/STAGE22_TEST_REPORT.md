现行RAG候选策略得到5001个原块、覆盖472个不同页面，经实际tokenizer形成5867个片段。参考文献及短文本等会被策略排除；**不是541页每个字都进入语义索引**。索引完整性指这份固定候选集的全部片段均存在。公式/图表恢复质量仍由其他未完成项管理。

原全结构按同一JSON口径约7.81 MB。分别检查第1、32、222、363、541页，每次只返回该页10/20/19/9/11个内容块，另带全局页信息、目录与书目，因此每页响应仍约1.1 MB；全局元数据重复发送是已知优化空间，没有宣称极小网络负载。

真实HTTP检查：[索引前](../output/stage22/api_before_index.json)、[索引后](../output/stage22/api_after_index.json)。五个页请求均通过；另4个页面读取并行完成。索引前问答为BM25降级，导入后为`bm25_dense_rrf`且无待索引项，`use_model=false`、无生成陈述。

导入后三题HTTP分别6.375/1.984/1.938秒；只是本机单次观测，不是冷启动或并发延迟保证。每条证据比对原ParseRun、原块全文、页码与坐标。

三题是已观察的工程探查，不计算相关性或答案准确率。例如线性回归题的HTTP结果包含第431页，并未证明命中预期第32页章节；M2-QUALITY继续部分实现。工程请求成功与锚点有效不能代替科学问题回答正确。
