日期：2026-10-29（北京时间），应用0.14.0。功能链路已接通，整体正式交付及自动综述学术质量仍未验收通过。

## 新实现

evidence_repairs.py增加本地候选预览、独立修订记录及保存响应的本地重新校验。界面可选择1—3条陈述，先查看候选再决定是否生成；生成后显示前后对照，打开新稿后另行核验。原稿和旧核验不覆盖，没有隐含追加模型请求。

补检索只使用每条陈述原先引用的文献与ParseRun，最多12次本地查询、每条8个窗口、每窗口1600字符。原块、相邻块和跨页候选分开锚定。英文上一页断词与当前片段须能组成原句/原引文实际出现的词，才加入候选；唯一候选可作为另一条原文引文补入，歧义不自动添加。这是有界词形线索，不证明语义连续。

同一证据的重复短引文可以扩大为真实连续原文范围，长度不得超过300字符，不用省略号拼接。保存响应回放只允许同一核验、同一组陈述，保留完整原JSON；不发起模型请求，不改写模型文本。修订仍经过来源范围、单文/跨文类型、数字与引文检查，全部保持semantic_verified=false。未来方向理由修订后不会自动认定解决，先保留待查。
