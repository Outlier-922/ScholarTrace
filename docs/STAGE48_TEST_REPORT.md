# 候选书目身份核对线索

日期2026-11-07，应用0.32.0。此轮减少相关题名和同作者候选被误当成原文所引论文的风险，保留读者对身份、用途及采用范围的决定权。

在发现结果的引用筛选表中，选择对应原文书目后会显示三类线索：标识符是否有对应及明确版本差异、规范化完整题名是否出现、候选首作者姓氏是否作为完整词出现。原文字样与候选标识符可对照。没有可比线索显示不足，不将缺失直接判成身份错误。

题名比较处理大小写、重音符、常见空白标点及字母间PDF断行连字符，要求完整词序连续出现；短题名或提取损坏可能无提示。首作者姓氏只是字面出现，不证明作者列表一致。arXiv DOI别名可提供同作品线索；原文明确版本时，无版本别名既不能掩盖错误版本，也不会把已对应版本误报为冲突。原文没有版本时，仅是作品层面的线索。

规则不计算可信度、引用价值分数，也不替用户采用或排除。保存人工筛选时，线索及规则版本一并保存，原始书目、原句、研究目的与决定仍各自独立。历史筛选及已存在的全文交接不覆盖，也不会因为新提示自动改变旧决定。
