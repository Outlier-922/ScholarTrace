3. 勾选“只看本地全文关系”可看20篇之间的62 条可计算边；指标继续基于保存时完整已对应子图，筛选不会重算。取消“显示待核对标识符”会隐藏相应待核对外部节点/边。可继续用一跳、用途与缩放筛选。
4. 点击圆点或用键盘Tab/Enter选节点，在相邻关系列表点边，查看书目原文。有正文入口时可展开“正文引用上下文”，查看对应片段并跳回 PDF。标为“本地标题与作者对应”的边有“目标全文身份依据”：展开后能核对目标全文完整标题、首位作者及两侧原文位置。

## 匹配范围

首先保留原有DOI/arXiv字面标识符规则；没有唯一标识符或标识符为另一个出版/预印本身份时，只在当前所选全文中寻找唯一的“完整标题＋首位作者”字面对应。标题来自第一页真实标题块，只有相邻、同字号、位置连续的行才作为续标题；姓名来自标题后的可定位姓名行，机构和竖排arXiv标记不能冒充作者。目标原块、页码、坐标和ParseRun保留。

标题相似、只有标题、同名多个候选、多标识符及明确注册冲突不会被此规则强行合并。没有补造DOI、作者、发表年或引用用途。参考文献区内按原生的行首作者年份标签分条，记录每条在原内容块内的字符范围。原生表格候选须有明确的书目标签或符合已有的书目续行条件。节点预算优先分配给已有注册记录的目标。

当前20/20来源能形成该字面身份候选，三篇缺失及一篇旧首作者组误认已修复，节点侧栏可查看姓名与原页，见[首作者说明](GRAPH_HEADER_IDENTITY.md)。候选覆盖不等于独立身份准确率，部分无编号关系可能继续遗漏。1171 组待解析候选中有 396 组因节点预算未展开。局部PageRank与入度用于当前子图结构分析，不证明论文质量、领域基石、创新性或方法继承。
