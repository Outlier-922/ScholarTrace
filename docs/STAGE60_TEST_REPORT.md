# 0.40.0 中文摘要学术英译

日期 2026-11-12。对应官网模块六“中文论文摘要或全文译为学术英文”。本轮实现并验证的是摘要/学术段落路径，每次最多4000字符；不宣称任意长度全文或所有学科翻译质量已经通过。

## 实现

“写作与绘图 → 学术英译”支持记录标题、粘贴中文摘要、可选术语表、一键生成、中英原文快照、历史读取和Markdown导出。原文保留SHA-256，明确标记为用户提供文本，不将引用标号当作已认证的参考文献。

每次最多1次模型请求、6000输出预留token。数字、公式、引用标记及术语经过占位符保护；结果检查数字一致、保护内容完整及英文输出。失败不保存伪译文。没有可用模型或没有启用生成时只返回原文。重复相同内容、标题、术语与模型/提示版本时复用历史，不重新生成。

## 真实模型与逐句核对

使用 `evaluation/academic_translation_cases.json` 中3段明确自建的中文文本，独立测试库。统计数字是合成例子，不是实际实验。每段先执行1次真实请求；首次“研究计划”例出现 `a evidence traceability` 冠词错误。原因是占位符遮蔽了术语上下文。

修复为同时提供占位符的原内容映射，模型仅用它理解冠词和搭配，输出仍保留占位符。提示版本从v1升级v2，旧结果保留。同样3段再次执行，每段1次请求，共6次真实请求。v2三个结果分别使用128、159、128个输出token；每次上限6000不是实际账单用量。

| 样例 | v2逐项复核 |
|---|---|
| 研究计划 | `an evidence traceability scheme`冠词正确；20篇、计划比较、实验未开展、不报告提升、不声称消除全部幻觉、非因果结论均保留 |
| 合成统计 | 合成声明保留；A/B分别75.0%/73.0%；2.0个百分点与2.0%区分；p=0.08不显著，未误译成等效或跨数据集优越 |
| 公式与引用 | LaTeX逐字保留；spectral clustering、root mean square error、RMSE正确；[12]仍待核对；may及仍需验证保留，相关性没有变成因果 |

以上为开发助手对照源文的逐句复核，不是独立专家盲评或跨学科准确率。v2仍是机器候选，界面继续提醒核对语义。首次与修复后记录均保存在 `output/stage60`。

## 页面和工程验证

独立Chrome在真实页面中填写原文、标题与术语，点击翻译，复用v2缓存并查看英文译文；Markdown与原文/译文逐字一致。本次页面操作新增模型请求0次。桌面和390像素窄屏截图已目视检查，内容可滚动阅读。

新增6项软件测试涵盖缓存持久化、导出、无模型、保护失败不保存、错误语言、公式引用术语和输入限制；不使用模拟回复证明翻译质量。TypeScript与Vite构建通过。最终完整回归801项通过，耗时336.37秒；仅有原有Starlette/httpx弃用提醒。主应用已重启，健康检查确认0.40.0。
