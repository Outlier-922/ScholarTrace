# 版本文本对照与原文定位

2026-11-09，应用 0.35.0。在阅读区选中已有可读同组文件的文献，点击「对照版本文本」。当前文件作为基准，另一侧可从同组可读文件中选择。结果每页展示最多 12 组差异，可从任意非空侧打开该组的首个 PDF 原文块。

## 官方样本复验

复用[阶段 50 隔离库](../output/stage50/official-replay.json)里的 Transformer v1 与 v7。两份文件各 15 页。逐页遍历对照结果，共 55 组，46 组两侧不同、4 组仅 v7 有文本、5 组仅 v1 有文本。交换基准和对照后，55 组逐项对应。对 101 个首块入口逐一回查了文件、解析记录、页码、块 ID 和摘录，共涉及 24 个「文件与页码」组合。回放未调用模型。

本机独立 Chrome 测试使用已有样本，验证第一、第二组列表可往返切换。第 9 组的基准侧链接从结构文本视图回到 v1 PDF 第 2 页并高亮文本块。对照侧链接切换到 v7 PDF 第 3 页，并高亮对应文本块。

后端全量回归为 774 项通过。固定双向对齐顺序后，重新执行了 2 项版本回归和官方样本复验。TypeScript 检查与 Vite 构建通过。
