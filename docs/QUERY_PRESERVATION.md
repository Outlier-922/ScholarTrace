# 具体查询词与PDF断词检索

适用0.24.2。[实际对照记录](STAGE30_TEST_REPORT.md)。

问答补检索现在保留问题中的英文术语/标识，每次最多12个、每个最多64字符；否定限制子句不作为正向检索词。原有章节、阶段、模型变体和字段提示继续使用，本地字段补检索总上限仍为12次，不新增模型规划或生成请求。

“最终配置”“配置”“设置”“策略”增加通用英文检索提示。PDF中的排版连字与跨行连字符在检索表示中处理，例如`conﬁguration`可匹配`configuration`，`mask-`换行`ing`可匹配`masking`。原来的词片段也保留，避免只拼接后丢失复合词检索。

这些处理只影响检索表示。PDF、原始内容块、ParseRun、文字摘要、页码、坐标和提供给模型的原文均不改写；现有语义索引无需因此重建。实际检索路径继续在回答中显示。

本轮保存的RoBERTa回答可从[本机记录打开](http://127.0.0.1:5173/?run=a2d76e0d-70fe-4580-93fd-b3d16b2cc630)。查看保存结果不调用模型，默认模型开关关闭；“训练目标/损失组成”的原文按钮回到第6页最终配置段。若重新提问，开启模型会产生一次新的生成请求；关闭则只检索。

目前该已观察开发题集的33个指定证据组均可找到，不表示所有自然语言问题都能完整回答，也不是答案准确率。复杂意图、否定和条件归属仍需按原文核验。
