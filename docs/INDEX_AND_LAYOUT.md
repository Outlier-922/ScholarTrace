# 索引准备与上标表示

正常提问时，界面会显示实际执行的BM25、语义融合或逐文混合检索。看到“部分文献尚未准备语义索引”时，可点该文献的“准备索引”，等待进度完成，再重新提问。这个过程只在本机运行，不调用付费生成模型，也不会下载权重；模型未准备时请先按README的本地语义模型步骤操作。

一次只准备一篇，重复点击同文献同解析会复用任务。失败/中断后可重新准备，已保存的向量批次会复用。索引与ParseRun绑定，重新解析后需准备新快照的索引；旧答案保留原版本，准备完成不会自动改写旧回答。索引计算期间本机CPU和模型锁可能占用较高，其他语义检索可能等待。

0.8.0开始，新解析的原生PDF会另外保存字体上标的`^{...}`表示。例如原始文字提取可能是219，但模型输入显示`2^{19}`；原文文本与坐标不变。上标可能是幂、脚注或单位，仍需看原页解释。这不意味着已实现LaTeX恢复；扫描OCR、下标、复杂公式和翻译版式仍有边界。

若某题仍缺字段，点击每条证据核对，不要把索引就绪或“来源检查通过”当成答案质量保证。详细实测见STAGE9_TEST_REPORT.md。
