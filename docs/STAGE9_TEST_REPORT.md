# 第九阶段：中文检索、逐文覆盖与上标表示

日期：2026-10-28。应用0.8.0；解析器记录版本3。基于第八阶段已观察的问题修复，全部20题已转为开发回归集，本轮没有新的独立留出质量结论。

## 改动及原因

1. 中文事实字段增加通用英文检索词、词形归一化；显式“第X节 / Section X”按真实章节路径排序，章节数字不再混入词袋。型号类字母数字词在有其他字段时弱化，减少型号成绩表占满候选。
2. 去掉预训练/微调的硬分层排序：一个段落可能同时报告“预训练设置”和“之后微调”，不能因出现两个阶段而排到低分背景后。BM25仍保留轻量阶段提示。
3. 多文问答逐文独立检索、轮流分配名额；每篇的语义索引状态分别记录。两篇、k=6时各有3条；某篇不足则让出名额。实际混合路径显示mixed，不把一篇未索引导致全部降级。
4. 原生PDF文本保留不变，额外保存有原文SHA256约束的`layout_text`。字体上标标记表示为`^{...}`，问答与比较的模型值使用该表示，数字检查也按此进行。原文摘录、页码、坐标仍指向原块；不将上标一概判为幂，脚注/单位需按上下文解释。
5. 对断句只在相邻、同章节、原生段落、页差不超过1、标点/大小写符合连续句且与查询字段相关时补最多一条；保留各自独立来源ID，不拼接伪造原文。候选总数仍不超过k。这是保守启发式，不是完整语义分句。
6. 新增显式本地语义索引任务与“准备索引”界面：固定文献/ParseRun、单任务并发、批次进度、同任务复用、错误脱敏；服务重启将未完成状态标为interrupted，重新准备可复用已保存向量。普通问答不会下载模型，也不自动为长文建立全部索引。

旧PDF需要通过“重新解析”获得新版式元数据，历史任务继续使用旧解析。语义索引按ParseRun分别准备；本地模型未显式准备/启用时按钮接口明确拒绝，不自动下载。索引占用本机CPU和模型锁，其他语义请求可能等待；本轮未作并发性能验收。
