## 总验收边界

表格依据用户提供赛题，区分必要功能、交付材料及建议的工程验收。独立人工复核、生产隔离和备份迁移不擅自当作主办方额外硬性条款；保留已知能力缺口。用户确认没有服务器和域名，公网尚未就绪。所提供规则只要求公网地址，并不强制购买独立域名；可运行后端的托管入口仍需准备。

check_acceptance.py检查状态和证明文件，存在必要缺口时submission_ready=false；发布时--require-ready返回非零码。空清单、没有必要项的清单、重复ID及无证明的通过项不能成为已就绪。文件存在本身不证明事实正确，表格依然是可审查的项目判断。

当前必要缺口包括公式LaTeX、复杂结构/长书完整资源验收、问答事实完整性、全文翻译质量、自动综述及已解决idea判断、意图闭环覆盖，以及仓库评审访问、最终PDF、MP4、公网和报名身份。没有通过增加一个小功能抹去这些缺口。

## 新实现

选区翻译支持原PDF鼠标选区、结构文本及选区变化提示。客户端按几何位置/结构块和唯一文本匹配确定所属段落，转换UTF-16到Unicode码点；后端强制核对document/ParseRun/block/page/start/end与原文。不能唯一匹配时停止，不把任意提交文本送给模型。

每次普通选区至多一次生成、输出预留1600token；数字和受保护内容校验失败不保存。代码、公式、表格及引用候选保持原文。缓存含选区范围和提示版本，历史解析可读、删除失效；请求返回前再次核对来源。界面旧请求中止及序号检查避免迟到结果覆盖新选区，但不能承诺服务商取消计费。

## 自动检查

新15项翻译检查覆盖确切子串、未选上下文不发送、缓存、七类错误范围/来源、数字保护、无模型、删除、公式保留、历史解析、生成中删除和非BMP字符。另有4项总验收门槛检查。最终全量279 passed、1条既有依赖弃用警告，30.81秒；结果见data/stage14_tests_final.txt与stage14-verification.json；此前275、278项过渡运行的计数和耗时一并记录，不用注入响应冒充真实模型质量。

TypeScript与Vite最终构建通过，1602模块，1.96秒。新增模块没有引入Python或前端依赖。评测指纹加入selection_translation.py，共15个文件；历史freeze继续保留，不能拿新产品覆盖旧结果。

## 一次真实生成与浏览器闭环

隔离服务端口8769，独立数据目录data/stage14_workspace；原文为明确标注的SYNTHETIC软件测试PDF。只对选区“The synthetic training batch size is 32.”请求一次DeepSeek生成，返回“合成训练批次大小为32。”，数字32保留。输出预留上限1600token，不是账单用量。没有翻译整篇PDF，也没有生成独立人工裁决。

先在结构文本选取，点击翻译；再用鼠标拖动原PDF文字层选同一句，界面点击命中cached，未再次生成。原PDF实际拖选成功，“所属段落”回原页并有1个高亮。一次缓存记录及源范围/块哈希见evaluation/results/stage14-selection-live.json。该句检查不代表术语、长文、不同语言或学术翻译整体准确率。

首次仅处理mouseup时，程序/键盘选区未显示提示，补入防抖selectionchange监听后验证通过。浏览器原生AX文本选择接口无法直接处理PDF透明文字层，改用基于实测坐标的真实鼠标拖选完成。未反复请求模型挑选更好译文。

桌面1280内容宽1265，390窄屏内容宽375，译文面板可见并能回原文；截图stage14-selection.png与stage14-selection-mobile.png。真实手机长按、旋转页、复杂双栏/OCR选区仍需扩大测试，所以总表把局部翻译保留为部分实现/待验收。
