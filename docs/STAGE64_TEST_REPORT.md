# 翻译上下文、跨页核对与单位保护

日期：2026-11-14 开发，2026-11-15 完成页面验证与收尾。展示发布材料仍由用户后续处理。

## 产品改动

翻译适配器从 translation-v1 更新至 translation-v4-context-units。每段至多附带三个、每个不超过800字符的同一解析版本邻近原文；目标段必须匹配原块ID和文本。小写开头的续段可参考上一页末段，排除包含多行纯数值的表格噪声。语境只用于消歧，不并入当前段原文或定位。

模型同时获得保护占位符的实际含义，输出仍须逐一保留占位符。原文中 `% point` 的数值和单位整体保护，避免还原数值后出现“0.6%个百分点”之类组合。数字校验、原文版本、缓存、批次请求预算继续保留。

跨页残句及 `% point` 单位存在核对提示，页面、JSON、Markdown和HTML导出可见。提示是启发式检查，不是错误分类器；校订后仍提醒结合原文核对。缓存使用新的提示版本，旧译文和旧任务保留；旧任务需要新生成时仍执行既有版本检查，不静默换版本继续。
