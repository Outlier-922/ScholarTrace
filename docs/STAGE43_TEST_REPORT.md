# 原文书目单层缓存展开

日期2026-11-06，应用0.27.0。此轮接通原文参考文献到候选核对与批量预览，只覆盖一层标识符缓存展开，不宣称完成自动联网递归搜索或引用价值筛选。

## 操作与实现

在阅读器“引用”页展开“从原文书目批量发现候选（本地缓存）”，选择至多5条原文书目，再点击展开。采用现有图谱的书目分条、续行与原页范围，固定当前ParseRun；不能提交其他解析版本的条目ID。

服务端从原文提取arXiv/DOI标识符，与已保存注册记录匹配。原文明确带arXiv版本时只匹配该版本；未带版本时保留缓存中的版本候选供核对。没有标识符或没有缓存匹配分别记录，不通过标题相似度自动补成同一论文。候选超过20条时拒绝并提示缩小范围，不保存悄悄截断的结果。

结果保存为发现快照，包含源文件哈希、解析版本、所选书目原文、原页与块、候选对应、未命中原因和内容摘要。打开快照后可在“原文书目到候选的对应与未命中记录”回查原PDF，再逐项核对标题、作者和版本。确认后沿用0.26.0批量入库，出版方元数据仍走原有单篇路径。展开本身不下载、不调用模型、不联网。

## 验证范围

7项专项检查通过，使用明确虚构的注册身份及合成PDF，覆盖原版本绑定、候选到批量预览、未命中分类、零外网、重复/超限/外来条目、错版本和删除源文档。测试不提供科研语义准确率。

首次完整回归721项通过、1项失败：测试假定只有一条候选，但同一会话其他用例已保存另一条合法缓存候选。修正测试的缓存隔离，产品仍保留所有匹配候选，不为满足数量断言删掉结果。

TypeScript和Vite构建通过。最终完整回归722项通过、1条既有Starlette弃用警告，用时129.26秒。新API及五项批量预览HTTP检查通过，预览未确认、PDF获取0。完整记录在核对JSON中。本轮无可用浏览器控制入口，未做页面目视或窄屏截图验收。

## 剩余缺口

当前依赖已有注册缓存。无标识符书目的标题/作者检索、无缓存时明确预算的联网查询、更深层有界扩展和引用价值筛选尚未完成。原文书目解析本身仍可能误分条，用户须核对原页。未改变M4-DISCOVERY的部分实现状态，整体正式交付未完成。
