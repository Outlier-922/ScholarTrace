# 多文对比：原文短语、引文与历史

适用0.18.0。入口：阅读工作台上方 **多文对比**。本轮收紧了“模型候选可进入表格”的条件，新增历史和首次响应导出；仍没有把候选当作学术事实认证。

## 直接查看本轮作品

1. 打开本机5173页面，点击“多文对比”。
2. 在“已保存比较”选择2026/10/29的DistilBERT / Learning Transferable Visual Models记录。系统读取保存结果，**不会再次调用模型**。
3. 两列显示训练硬件原文短语、同引文中的模型条件及实际引文。左列定位PDF第3页，右列定位第5页。点击“采用引文所在块”展开原段，再点击“定位原文块”。高亮的是原文块，不是精确字词的图像范围。
4. “完整来源与响应JSON”保存确切解析版本、全部候选块、引文/值/条件的原文字符范围及首次模型JSON响应；Markdown适合阅读。已有真实结果已追加到本机历史，未导入合成反例或早期错误记录。

## 新建比较

选择2—5篇已就绪/部分可检索文献，以及1—8个维度。“启用模型抽取”默认关闭；关闭时只在本机检索、显示原文匹配或候选，不请求服务商。开启后每篇至多一次请求、每次最多2500输出token预留。服务未配置、预算不足或调用失败时保留原检索结果，不用记忆补空。

加载历史后，文献和维度勾选同步为该记录的范围。再次点击“生成对比表”会新建记录；是否允许模型取决于当前模型开关。旧记录不被覆盖，历史查看和导出不产生模型请求。

## 每格怎样检查

- 一格只附一个本篇、本维度候选的证据ID；不能借用别篇或相邻证据中的数字。
- `support_quote`是8—1200字符的连续原文，必须能在指定块唯一定位。允许折叠换行/空白进行匹配，最终保留真实原文与字符范围。
- `value`和非空`conditions`必须分别是这段引文中的连续、唯一短语，保留原文大小写；当前不接受自由翻译或改写。条件不明确时留空。
- 再以这段实际引文检查数字与明显公式残片，不使用整段其他句子或版式元数据替它提供数字。
- 接受后状态为`quote_bound_candidate`，`semantic_verified=false`。页面称“引文绑定的原文短语”，不称事实验证通过。

“同引文条件短语”只证明这些字出现在同一引文中，**不证明条件与数值的语义关系正确**。跨句指代、否定、他人基线、实验阶段以及指标可比性仍须人工读原文。完整NLI和数学核验未实现。一个引文包含多个配置时仍可能需要更细的人工核对。

重复维度、值/条件不在引文、来源不符等会留下“未采用的模型候选”及原因，保留原检索结果。不能把被拒绝的模型文字当作事实。未返回某格也不表示整篇论文没有报告。

## 原文匹配与历史边界

原文硬件匹配新增GPU/TPU时间量过滤，避免把`GPU years`、`GPU day`等当作设备数量，并识别带显存的连续设备表述。该规则仍是有限词形匹配，不确认数量属于本论文，不支持所有硬件名称/书写格式。无模型模式显示的“原文匹配”也应核对上下文。

来源固定到文献、ParseRun和原块。生成完成及读取历史/导出时重新检查原文、页码、坐标；确切解析版本缺失、原块变动或已存引文范围不一致时，不继续返回该记录。重新解析但保留旧快照时仍可核对旧版本。

旧比较记录保留旧状态，页面明确“旧检查规则”，不自动标成新规则通过。历史入口最多返回最近50条中的20条可用版本记录，属于本机共享文献库，不是多用户隔离。

正常首次模型JSON保存在`model_outputs`。单篇响应超过40000字符时只保留摘要并显式标记`truncated`；单项提案超过8000字符时保留有界字段并标记截断。每维度最多记录8份提案、只处理响应前64项，完整正常响应可在JSON中审阅。这些是资源边界，不是语义安全保证。
