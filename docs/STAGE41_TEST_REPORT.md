## 改了什么

先前补证据修订只收到原句和候选原文，没有收到核验标出的缺句或范围问题。现在修订请求从绑定的核验记录提取所选条目的状态、理由、不支持片段、范围说明和本地范围提醒；仍只允许使用原论文、原ParseRun的限定候选。核验意见是问题线索，不是事实证据。

核验增加独立scope字段和可追溯的原句片段，并给引文增加同一论文的匿名分组编号。范围更大不能保留完整支持，范围不明或输出缺失保留待查。界面和Markdown显示范围理由。提示及本地校验版本分别参与缓存，旧结果不覆盖、旧格式仍可读。

真实模型仍漏判后，增加有限字面词规则：实际短引文包含our model(s)、our experiment(s)、we perform/train/evaluate等作者设置词时，保存原文子串；即使模型建议支持，也先放入待核对区。这是保守提醒，不是通用语义识别器。已经限定范围的正确陈述也会被保留待查，未命中亦不保证正确。
