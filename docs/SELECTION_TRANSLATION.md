# 选区翻译（0.11.0）

打开原PDF，用鼠标拖选词或短句，或切到“结构文本”选择原文。显示选区面板后选中文/English，再点“翻译选区”。选中本身不发送模型请求；不做悬停即自动计费。手机支持浏览器文字选区变化提示，但真实移动设备操作仍待扩大验收。

面板显示确切原文和译文。“所属段落”回到原PDF高亮所属内容块，定位范围是段落，不声称逐字坐标。页码、文献或解析版本切换会清空选区并中止界面等待，迟到响应不会覆盖新选区；已经到达服务商的请求不保证可取消计费。

当前一次限制为同一页、同一内容块内的1-1000字符。原PDF以选区屏幕位置和解析坐标共同找块，结构文本直接读取所属块ID；再按原文查找字符串。重复短词、跨段/跨页、断词与版式不一致等无法唯一匹配时会要求缩小范围，不猜测来源。OCR选区仍受识别质量影响。通过键盘选择和移动选区变化会触发提示，界面已加防抖。

翻译缓存绑定文献ID、ParseRun、块、确切起止位置、原文、目标语言、提示版本及模型标识。不同选区不覆盖整段任务；历史解析继续可查，来源删除后不可读取。默认只读共享演示不能提交翻译，模型未配置时显示原因；已有译文可在源仍有效时离线通过记录接口读取。

后端只向模型发送核对后的原文子串，普通文本至多一次调用、预留1600输出token。数字、URL、公式占位符等沿用保护检查；公式/代码/表格/参考文献候选保持原文并标记preserved。不完整公式恢复、术语消歧、全文学术质量都不由这些格式检查证明。

接口：POST `/api/selection-translations`，必填document_id、parse_run_id、block_id、page、start、end、source_text、target_language。start/end是Unicode码点的半开区间，不是UTF-16单元；服务器从固定来源取原文并核对source_text，不接受任意文本伪装成论文。GET `/api/selection-translations/{id}`读取并重新核对来源。

本轮只对合成短句做一次真实生成，另一次同句POST命中缓存；结果不作为独立学术翻译质量评测。完整记录见STAGE14_TEST_REPORT.md。总体完成状态见ACCEPTANCE.md，新增功能不代表参赛作品全部完成。
