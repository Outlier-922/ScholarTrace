# 必要能力收尾：任务内 CSV 科研绘图

客户端日期2026-10-30；应用0.22.0；基线19786a3。此记录验证确定的绘图规则、任务预算与复现过程，不验证虚构数据的科学价值，也不替代整体赛事验收。

## 实现与固定范围

- 新增第九个白名单工具 `plot`，沿用科学绘图六种模板。任务内导入/选择CSV，明确横轴、指标、分组/重复标识、聚合、缺失、误差条、单位及雷达方向/边界；Studio与Task共用配置控件。
- 模型规划前校验CSV及规则，缺数据/无效规则立即拒绝。任务保存原CSV SHA-256、数据状态、完整配置、运行时指纹与计算预览；初始计划历史含绘图配置摘要哈希。
- 绘图在任务工具预算内执行，不调用模型。执行前后核对数据与绑定；中断后复用已注册的确定产物ID，完成的原文步骤不重做。数据或运行时变化、未知异常均停止，不自动改规则。
- 导出固定名称的图/原始CSV/处理后CSV/清洗与归一化记录/图注/环境/重画脚本，并核对每个文件哈希；文件变化返回409，拒绝导出不一致包。
- CSV独立于固定论文来源，不把演示数值写成论文实验，也不自动交给模型改写成事实。图和图注均保留自建演示标记。

[使用说明](WORKFLOW_PLOT.md)；代码与原文快照先固定在[56文件冻结v1](../evaluation/freeze_stage26_workflow_plot_v1.json)。本轮真实外部模型/书目请求上限0，实际0。完成后仅删除测试文件末尾多余空行，另存[最终56文件冻结v2](../evaluation/freeze_stage26_workflow_plot_v2.json)，产品代码、规则和输出未变；未追加运行请求。Git对本轮解压重画目录与首次原始失败日志保留原始字节，避免行尾转换破坏已记录哈希。

## 首次失败与修复

首次相关检查93项中1项失败，原日志保留于[focused_first](../output/stage26/stage26_focused_first.txt)。开启任务模型许可但仅请求绘图时，初始证据步骤虽禁用生成，因未命中文献插入的补检索没有继承 `model_allowed=False`。测试用禁止生成的桩拦截了该路径，没有真实付费请求。

修复为补检索继承原证据步骤的模型许可；也保护既有纯书目发现路径。第二次CSV/发现/反馈检查58项通过；最终全套544项通过。[最终日志](../output/stage26/stage26_full_final.txt)中旧的调度失败用例有预期ERROR日志，对应用例通过；不是新增运行故障。唯一警告仍为Starlette/httpx弃用。TS检查及Vite生产构建通过（首轮构建3.37秒）。未覆盖或删除首次失败。
