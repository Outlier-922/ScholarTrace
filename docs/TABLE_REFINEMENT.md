# 表格原图、行列重建与手工修订

入口：文献与阅读 → 打开论文 → 页码 → **表格**。支持原生 PDF 文字重建和扫描表格框选识别，均在本机运行。

扫描页勾选“识别扫描表格”，拖动框住完整表头和数据，避开表题、脚注和正文。点“标记表头下缘”，在表头和第一行数据之间点一下，然后选择“本机识别并重建行列”。自动分列有误时可在区域设置中输入原页列分界再重建。不需要重新解析 PDF，也不配置大模型。新环境安装项目依赖后，在运行作品的 Python 环境执行 `python scripts/prepare_local_models.py --ocr` 准备本机 OCR。样例见[扫描表格实测](STAGE68_TEST_REPORT.md)。

## 使用步骤

1. 在“已有表格候选”选择一张表。系统带入区域和表头下界；旧候选可能把多行、多列合到了一格。
2. 点击“按表头重建行列”。先对照原图和蓝色分界线，核对是否覆盖完整表头与数据。文字行并不一定等于一条完整实验记录。
3. 如果本页没有候选，展开区域设置，输入左、上、右、下和表头下界。所有数字都是**相对于原页**的百分比。例如左20%、右80%表示取中间60%的页宽。不要包含正文、表题或脚注，表头下界应在表头与首条数据之间。
4. 自动列界不合适时，输入内部列分界，如`35,55,75`，表示在原页宽度35%、55%、75%处切列。再次重建会保留另一份来源，不覆盖旧结果。
5. 查看新网格、跨行分组和待归列提示。未提取值保持null，不按“同上”填值；跨列文字或相连表达式被保留在待核对原文中。
6. 点击单元格，编辑文字或勾选“此位置未提取值”。可以修改列名，但只能保留当前行列尺寸与跨行覆盖关系。另一个位置或切列方案应重新建立来源。
7. 填写修订说明并“另存表格修订”。原候选、旧稿和备注保留。修改过的单元格用浅黄色提示；手工版本也不会自动标记为已核验。
8. “原页定位所选单元格”回到原 PDF。有识别文字的扫描格高亮实际 OCR 框，未识别格高亮推定格位。待归列的 OCR 片段也可直接定位。打开“表格”后可以从来源历史继续查看。
9. 导出 CSV 用于后续数据处理，同时保存“完整来源 JSON”。CSV 不能保留跨行、null 与手工空字符串的区别。JSON 保存原图摘要、文件摘要、解析版本、区域、文字与坐标、原候选、手工稿和变化；扫描片段另存字符识别分数。

宽表在表格区域内横向滚动。扫描裁图没有识别到有效文字，或无法分出表头和数据时，界面提示调整选区。OCR 候选里的连写、公式符号和上下标须对原图核对。

## 来源与边界

来源绑定文件SHA256、ParseRun、页码、页面几何、区域和可选原候选；重新解析保留历史，删除文献后相关来源、修订和裁剪失效。每篇最多读取最近100条来源或修订。

重建使用表头文字位置建议列界，按文字基线分行。跨行分组仅在原候选已有对应几何且能够绑定时保留，不是一般性的合并单元格识别。带上标的原生词可用`^{...}`保留字体提示，但仍需核对数学含义、单位和指数。

最多 2000 个原生词或 1500 个 OCR 文字片段、150 个文字行、40 列、2000 个单元格；单元格修订最多 1000 字符，整表修订文字最多 10 万字符。扫描表格需要用户选区，旋转页、跨页表格和通用合并关系暂未支持。

修订不覆盖原解析，也不写入全库问答索引。已保存的原生来源可以整表或按行加入当前问题，手工变化只作独立对照，详见[表格问答](TABLE_QA.md)。扫描表格候选暂时只用于原图对照、修订和导出，问答接口也会拒绝把它当作证据。
