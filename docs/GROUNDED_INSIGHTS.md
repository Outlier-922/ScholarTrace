# 自动综述草稿与未来工作全文核对

综述草稿功能自 0.12.0 接入。0.25.5 的数值检查只使用实际所附引文，并分别核对模型标识与实验数值。草稿及修订页面会提示两类未保留原因，整体学术质量仍待验收。[历史记录](STAGE15_TEST_REPORT.md) · [本轮回放](STAGE37_TEST_REPORT.md) · [总验收表](ACCEPTANCE.md)

## 如何使用

1. 双击根目录“启动科研助手.cmd”，等待文献解析完成。模型由根目录.env读取；请勿把密钥写入文档、截图或导出材料。
2. 打开“引用图谱”，选择论文及确切版本，填写主题，构建图谱或打开历史图谱。注册源元数据只用于书目身份核对，不替代论文全文。
3. 切换“自动综述与方向核对”，选择1—8篇图谱来源，点击“生成带引用的综述草稿”。一次操作至多一次模型请求，预留最多2400输出token；不是账单用量。超出8篇请分批整理，目前没有20篇自动合并综述功能。
4. 阅读各节的候选陈述，展开“逐字引文与原文位置”，点击论文与页码回到原PDF高亮段落。“论文覆盖”只表示有无保留的候选陈述，不表示论文已被完整阅读或正确总结。被拒绝条目数量也会显示。
5. 在“未来工作全文核对”选择原文方向，可缩小为同段内的连续子串，最多1400字符。勾选1—3篇已经入库解析的候选全文，点击核对；一次至多一次请求，预留最多1800输出token。同篇或同一作品的其他版本不能当后续独立研究。
6. 当前另可点击“核验陈述与所附引文”进行一次模型复查，查看待修订原句；步骤、成本与已知误判见QUOTE_SUPPORT_CHECKS.md。原稿与研究任务导出不会被自动替换。核验后可按需补充原文和创建修订稿，另见EVIDENCE_REPAIRS.md。
7. 历史下拉框可重新读取已保存结果，不触发生成；导出证据Markdown包含原文、文献、ParseRun、块与坐标。重新点击生成会创建新记录并可能计费，不是缓存按钮。

## 检查到底证明什么

综述从每篇的摘要候选与主题检索中取最多4个片段，每个模型输入片段最多1400字符。提示要求研究背景、方法、跨文综合和局限四类内容；服务端最多保留8条陈述，每节最多4条。某类证据不足可以缺节，不能据此声称该领域没有相关研究。

保留陈述需通过来源ID、单文/跨文归属、短引文和数字检查。跨文综合至少涉及两篇。PDF中的空白、兼容字形和英文行末断词可作有限规范化匹配，必须能反向找到原文；保存原文子串、模型引文和映射范围，不做拼写、大小写或数字模糊修正。规范化后歧义匹配会被拒绝；完全相同短语重复时取第一处。范围相对模型输入片段，不是PDF词级坐标。部分版式来源使用已绑定原文哈希的上标表示，仍应对照原页。

这些检查**不证明陈述被引文语义支持**，现在有单独的所附引文模型复查，但没有独立人工事实裁决或通过质量评测的NLI模型。模型可能在同一条话里添加引文没有支持的限定、因果或否定。所有结果都标记semantic_verified=false，必须查看原段落及前后文；不要将草稿直接当作可提交的学术综述。

未来工作核对必须同时引用原方向及指定候选的全文片段。只对给定片段比较，不自动遍历互联网或读取其他候选全文。仅当模型建议addressed、双边引用通过检查、且候选确切版本日期严格更晚，才放入“模型建议已有处理”临时分组；原方向始终保留，分组可以展开复核，不表示已确认解决。

可接受的版本日期来自已缓存arXiv确切版本记录、入库标识符、文件哈希和版本标签的对应；只按日比较，同日先后未知。手动上传、仅有发表年、标识符/版本/哈希冲突均不据此认定后续进展。日期未知、部分涉及、较早、输出重复或引文无效时保留待核对。**保留不证明尚未解决，更不证明有创新性。**

## 与研究任务衔接

“研究任务”新增“生成溯源综述草稿”工具。规则可识别综述意图，模型规划只能从六种既有工具选择。输入来源和解析版本固定，任务内部建立只用本地书目/缓存的来源图谱，不自动请求注册源。内部构图与综述作为一个复合工具步骤计数，模型请求仍受共享模型预算独立计数。

启用模型时生成草稿；关闭模型或模型预算耗尽时只保留原文提纲，并明确提示未生成学术综述。模型未配置或服务失败会显示失败，不伪造成功。任务中断发生在已保存结果之后，恢复复用确定产物ID；发生在保存之前的服务请求仍可能已计费。任务ZIP可包含review.md，依然带待核验提示。

界面历史和导出均绑定原文件SHA256、ParseRun和块内容/坐标。重新解析后旧结果可查旧版本；来源删除或失效后结果不可读，并清理涉及该文献的记录。受控只读演示只能查看历史；新生成继续受演示认证、小时额度和任务预算约束。

## 当前应避免的结论

不能称为全领域综述、事实准确率达标、已解决方向自动确认、自动发现创新、20篇规模质量通过或完整自主重规划。当前优先补足证据检索与逐条语义核验，并用未参与调试的新论文检验；实际Transformer/BERT烟测已经暴露语义支持不足，不应只挑较好结果展示。
