# 第三阶段实测记录（0.3.0）

日期：2026-10-27。环境沿用第二阶段的 Windows、Python 3.12、本地 ONNX 与 Node.js 24。官方 PDF 原件未改动，生成模型未配置，未发起真实论文翻译。

## 本轮交付

1. 多文事实矩阵：2—5 篇文献，8 个可选维度；先固定各文献 ParseRun，再逐文逐维检索。单元格区分原文匹配、候选证据、未找到证据及可选模型来源检查。逐格跳原文、保存结果、Markdown 导出。
2. 正文数字引用：支持单编号、逗号/分号组合与有界范围；只有唯一匹配的书目编号才建立连接。组合引用先选择条目，原文与 References 可双向跳转，保留返回入口。作者年份引用不自动猜配。
3. 翻译任务：段落、本页、全文/接口页码区间；术语表、原译对照、段落锚点联动、SQLite 检查点、任务历史、缓存、重试、HTML/Markdown 导出。模型、ParseRun、原文、语言、术语表和提示版本参与任务/缓存绑定。模型变化时阻止混用结果。
4. 保护与降级：数字/公式/希腊字母/代码/引用占位符及数字数量检查；代码、公式候选、表格与书目保持原文；未配置模型的翻译返回 503，不生成伪译文。删除来源时清理依赖产物，并防止正在等待模型的任务重新写回已删除来源。
5. 修复 PDF.js 全量阅读器样式与应用 `.sidebar` 的冲突，只引入带上游许可的 TextLayer 样式子集。

## 自动化与构建

- 全量 `pytest -q`：**70 项通过**，包括原 49 项及新增 21 项。
- 新增测试验证逐文证据隔离、错误来源 ID/新数字/非逐字引语拒绝、源删除竞态、数字引用反向关系、范围上限与重复编号拒绝。
- 翻译测试验证占位符丢失/重复/未知标记拒绝、数字增添拒绝、缓存失效条件、失败检查点重试、模拟中断后的 SQLite 恢复、模型切换阻止混用、HTML 转义和导出 CSP。
- 模型适配器用注入 HTTP 客户端检查 JSON 参数、DeepSeek 非思考模式、禁止重定向和无效地址拒绝。**这些模型结果都是测试注入，不能充当真实模型效果。**
- TypeScript `tsc -b` 和 Vite 生产构建通过。TextLayer CSS 产物由全量约 280.53 kB 降至约 2.93 kB（未压缩）。
- 测试库仍有一条既有 Starlette/httpx 弃用提醒，不影响本轮测试结果，后续升级依赖时处理。

## 官方文献真实 HTTP 验证

`scripts/verify_stage3.py` 面向本机已导入文献，不上传或删除原件，不调用翻译模型。输出保存在忽略 Git 的 `data/stage3_official_report.json`。

| 检查 | 结果 |
|---|---|
| Transformer v7 数字引用映射 | 63 个正文标记，76 条条目反向关联 |
| BERT 数字引用映射 | 0；正文主要使用作者年份格式，明确不强配 |
| Transformer v7 / BERT，4 维度、8 单元格 | 所有证据均属于本格文献及固定 ParseRun |
| Transformer 训练硬件匹配 | 原文摘录 `8 NVIDIA P100 GPUs`，标注条件待核验 |
| BERT 训练硬件匹配 | 原文摘录 `4 Cloud TPUs`，标注条件待核验 |
| 优化器匹配 | 两篇均找到 `Adam` 原文；不据此宣称超参数相同 |
| 模型结构、训练目标 | 保留候选证据，未伪造已抽取的事实值 |
| 对比 Markdown 导出 | 包含两篇具体 ParseRun 与内容块 ID |
| 未配置模型翻译 | 返回 503 |

第一次 4 维度比较约 2.359 秒；缓存后的复现脚本约 0.359 秒，包含导出检查。这是单机观测，不作为性能保证或并发指标。

当前解析返回 85/109 个书目候选片段，包含未编号片段和续行，**不是 85/109 篇已核实参考文献**。本轮不宣称完成书目身份识别、跨论文引文图谱或作者年份关系抽取。
