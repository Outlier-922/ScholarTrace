# 跨论文问答与自主工具复验

2026-11-16。使用官方 QLoRA v1（`2305.14314v1.pdf`）与 DPO v3（`2305.18290v3.pdf`）。固定两个 PDF 的摘要和解析版本。用户问题分别问两篇的训练目标、更新或冻结的参数或策略，并问 DPO 如何使用参考模型。自主任务另要求构建引用图谱。预期答案留在验收检查中。

首轮直接问答只返回两项训练目标。自主任务前两轮各答一篇，之后额外生成了综述，在四次工具调用时达到预算上限。修复后系统按子问题和论文范围补检索，后续检索会合并同版本前一轮证据，仍最多保留 12 个片段。界面在任务中显示字段覆盖、尚缺内容和原文跳转。

| 实测 | 结果 |
|---|---|
| 直接问答 | 5 个候选字段均返回。QLoRA 的训练设置、冻结量化基础权重与更新 LoRA，分别可回查第 8、14 页和第 1、3 页。DPO 的训练目标及实际优化语言模型策略可回查方法描述，参考模型的来源和损失用法对应第 4、20 页。 |
| 自主任务 | 模型选择词项检索→引用图谱→停止。覆盖同样 5 项，图谱有 64 个节点和 63 条边。执行 2 次工具、4 次模型请求，预留输出 3400 token，活动时间约 13.3 秒，书目请求 0 次。 |
| 关闭生成 | 规则任务完成原文检索和图谱，模型及书目请求均为 0，事实陈述为空。 |
| 网页与原文 | 从研究任务历史打开最终运行，看到 5/5 候选字段。点击参考模型字段跳到 DPO PDF 第 4 页并高亮。所有保留证据的文献、解析版本、块文字、页码与坐标均与本机原文记录一致。 |

人工核对发现，中间一次虽填了参考模型字段，主要引用了背景 RLHF 段落和实现的输入说明。最终检索把第 20 页实际损失计算保留下来，可以核对当前策略与参考策略的偏好对数比之差。最终候选用代码变量表示该关系，仍可进一步改善解释。输出的候选回答和定位明细见[验证记录](../output/stage71/verification.json)，界面见[网页截图](../output/stage71/task-coverage.png)。

853 项完整回归通过，保留一条既有 Starlette 弃用提示。TypeScript 检查和 Vite 构建通过。最终真实任务一轮检索即齐备，两轮之间保留原文的路径由定向回归验证。此次复验覆盖这组论文与这类问题，其他跨文推理及翻译、发现等工具组合的质量仍待验收。
