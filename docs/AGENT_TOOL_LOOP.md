# 模型自主选择工具

0.39.0 将老师建议落实为独立的“模型自主循环”模式。规则流程和一次性模型建议仍兼容历史任务。对应赛题的自主工具调用与闭环探索能力，不代表其余赛题能力已全部验收。

## 使用

打开“研究任务”，选择文献并填写目标，将“任务规划方式”设为“模型自主循环 · 逐步选择工具”。需要生成回答、译文或综述时，勾选“执行时允许模型生成”。检查预算后生成计划，再开始执行。

自主模式的初始步骤列表为空。每轮请求包含工具说明、参数约束、固定来源、实际执行观察和剩余预算。模型返回一个工具调用或停止意图，服务端校验后执行。每步结束后，模型读取结果再决定下一步。页面的“自主工具决策”显示选择依据与检索词；这些文字是模型的调度说明，不作为科研答案。

没有配置模型时使用规则模式。配置了模型但关闭生成时，自主模式仍消耗调度请求，工具结果仅展示原文及本地产物，不生成回答或译文。调度与生成共用任务的模型次数和输出预留预算。工具次数、活动时长及书目联网额度另外检查。

## 工具契约

工具说明随每轮请求发送，见 `backend/app/workflow_agent.py` 的 `DESCRIPTIONS` 和 `catalog`。协议采用严格结构化 JSON，可用于当前兼容接口，不要求服务商支持原生 function-calling 字段。

| 工具 | 模型可决定的内容 | 固定边界 |
|---|---|---|
| 词项检索 | 查询词、是否继续补查 | 固定文献版本，返回原文锚点 |
| 混合召回 | 查询词、调用时机 | 复用已准备语义索引；缺失时报告 BM25 降级 |
| 表格原文问答 | 查询词、调用时机 | 原生表格内容块；不补造缺失单元格 |
| 翻译 | 选择哪个已固定范围的翻译步骤 | 用户指定段落或全文范围；全文批次仍单独确认 |
| 文献发现 | 选择哪个已允许的提供方步骤 | 用户固定查询与联网方式；不自动扩大全文库 |
| 多文对比、引用图谱、综述 | 是否调用及顺序 | 固定来源、比较维度和现有核验机制 |
| 写作框架、CSV绘图、流程图 | 是否调用及顺序 | 写作仍是计划；CSV与统计规则由用户确定 |

检索允许使用不同查询再次调用。重复的相同调用、未知工具、多余参数、任意来源替换均拒绝。其他工具完成后不再提供相同调用。模型提前结束时，未完成的请求工具写入缺口。

## 结果与恢复

执行仍调用原有服务，保留来源版本、页码、坐标校验，以及现有引文与数字检查。自动检查通过不等于语义正确。模型返回的停止说明不能覆盖工具结果或清除待核验项。

模型失败后按用户选择停止，或在允许的恢复次数内转入原文与本地工具流程。恢复不继续调用模型，不新增联网请求。预算不足时保存检查点，用户明确提高预算后才继续。已完成步骤不会重做；中断中的外部调用仍可能已计费。异步超时会中止等待和后续调度；正在运行的本地线程不能保证立即终止，不能将该限制描述成操作系统级强制中断。

JSON任务导出包含全部决策、调用参数、真实结果、来源、预算与事件。旧任务保持其原规划模式，不自动升级。
