# 不改代码，配置 DeepSeek

1. 打开 [DeepSeek 官方 API Key 页面](https://platform.deepseek.com/api_keys)，登录或注册你自己的账号。在 API Keys 中创建一个 Key，可以起名 ScholarTrace，然后复制。平台界面如有账号协议或支付操作，由你自己确认。
2. 打开项目文件夹，双击 **配置模型.cmd**。出现黑色终端窗口后，粘贴刚复制的 Key，再按 Enter。
3. **粘贴时看不到字符是正常的**，用于避免回显密钥。不要把 Key 发到聊天，也不要截取包含密钥的网页。
4. 程序自动填写端点、型号和参数，保存到项目本机 .env，并发送一次不含论文的小请求。看到“连接成功”即完成。若失败，窗口会显示不含密钥的错误提示；检查账号可用额度、Key 与网络。
5. 关闭此前运行的本地服务，双击 **启动科研助手.cmd**，在浏览器打开 http://127.0.0.1:5173 。回到聊天只需回复“已配置”。

配置文件 .env 是本机明文配置，已经排除在 Git 之外。不要将它随作品提交或发给别人。配置窗口不会回显 Key，也不会上传到聊天；实际模型调用仍需将所选内容发送到你配置的服务。

此入口默认使用 DeepSeek。官方当前示例的端点为 https://api.deepseek.com，型号为 deepseek-flash；不同于网页聊天登录。[官方接入说明](https://api-docs.deepseek.com/quick_start/agent_integrations/)。

如果你已经有 OpenAI API Key，终端可运行 .venv312/Scripts/python.exe -X utf8 scripts/configure_model.py --provider openai，输入账号可用的模型名和 Key。无需安装其他插件。
