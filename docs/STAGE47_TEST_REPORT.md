# 有界多层参考文献展开计划

日期2026-11-06；应用0.31.0。此轮将已确认全文的逐层展开组织成共享预算、可恢复的计划，不宣称无人值守自动获取或全量文献收割。

## 使用方法与约束

进入“发现与追踪→多层展开”，从可用的全文交接选择起点，明确层数1—2层、全文数1—5篇（含起点）和整份计划联网预算0—3次。0表示只读缓存；大于0表示允许将选中的书目条目发送至既有官方注册接口。计划不调用模型或自动获取PDF。

起点深度为0。为每个可展开节点选择至多5条原文书目，调用既有书目发现；下一层必须先在本层候选中核对身份并关联全文，再回到计划刷新，将该交接加入下一层。筛选后另存的采用项快照也可接回其原父节点；来自其他搜索的交接不允许接入。仅明确入库及确认的全文成为计划节点，候选元数据不当成全文。

各节点固定文档ID、SHA-256及ParseRun，并保存父节点ID和发现快照。采用已有作品键（arXiv根标识符或本地作品身份）阻止同作品跨版本重复与循环；未识别为同一作品的别名不具备一般去重保证。层数与节点数属于整份计划的限制，不随分支重新分配。

联网实际发送前将用量写入共享持久账本。跨层、跨节点及明确重试共享同一额度，中断不会退回已经预留的次数。节点至多执行2次，不自动重试。执行前保存所选书目原文及页块，便于中断时导出实际输入。旧修订号不能重复推进，已完成节点不重复执行。服务重启后的执行中节点显示中断，读取原选择后可明确重试，沿用既有单API worker运行范围。

从历史可重新打开最近20个计划。“导出全部层级与来源”包含计划、各层发现快照和全文交接，可独立核对来源；不是只有一组数据库ID。达到深度上限的全文可保留为叶节点，但不再继续查询其参考文献。

在本层新快照中明确关联已有官方Layer Normalization v1，接为深度1的子节点；它的父节点及原解析版本保留。再按原顺序展开这篇论文前5条书目，返回0个缓存候选，原条目与未命中原因保存，没有联网补齐，也没有把0结果解释为不存在论文。

## 剩余工作

该计划提供明确范围的多层操作与追溯，不自动确认身份、判定引用价值或生成科研结论。部分书目解析和身份识别仍有边界，网络候选与无缓存条目需要核对。自动引用价值、复杂研究意图与科研输出质量仍待验收，正式交付材料及公网条件未齐；整体状态继续按总验收表保留未完成。
