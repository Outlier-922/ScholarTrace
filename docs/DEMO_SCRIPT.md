# 7分钟演示脚本（0.9.0录制前排练版）

依据用户提供要求：MP4、5-8分钟、至少1080p、普通话。目标7:00，实际成片时长和分辨率需再次检查。本文件不是已录制视频。

建议备答：为什么不用全自动自由代码？因为当前目标是可检查、可预算和可恢复的工具链。为什么不宣布准确率？因为来源位置核验与语义正确是两件事，独立人工复核尚未完成。为什么称工程创新？因为本作品解决版本漂移、比较溯源和任务恢复的具体问题，尚未证明原创算法优越性。
