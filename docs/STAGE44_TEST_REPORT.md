已有本地命中的条目不自动联网，除非用户明确改词。无缓存且含多个不同标识符时要求改词，不擅自选择。逐条最多返回3个候选，整个快照至多20个候选。每条保存实际检索词、服务、缓存状态及成功/无结果/失败/限流/预算耗尽；失败不自动重试。结果中的来源状态区及原文对应详情均可查看。

请求只访问既有arXiv/Crossref固定官方端点，沿用缓存、请求间隔、超时、返回体大小与重定向限制；只发送所选书目条目或明确改词，不发送PDF正文。实际请求计数由底层发送前的guard累计，缓存命中不消耗外部请求数。单次展开不调用模型、不获取PDF、不自动确认论文身份。
