# 从核对后的全文继续研究

功能自0.23.0接入，当前0.26.0。交接把书目快照与已入库全文联系起来，并将确切文件和解析版本带入一个新任务。[实际记录](STAGE27_TEST_REPORT.md)。

## 操作

1. 在“研究任务”的文献发现结果点击“打开此检索快照核对与入库”；也可以从“发现与追踪”独立检索。打开保存快照不会重新联网。
2. 如果文献已经在库，点击“查找本地全文（不联网）”。选择具体文件，核对标题、作者与版本，勾选确认后点击“关联本地全文并准备后续任务”。arXiv候选必须确切版本一致；其他书目仅用标题字面一致缩小候选范围，不自动证明身份。
3. 如果尚无全文，可按原有路径核对arXiv标题/作者/版本后点击“获取 PDF 入库”。获取完成会自动保存交接记录。出版方只有元数据时，继续从原站核对开放全文并手动上传，再关联本地文件。不会从任意元数据URL自动下载。
4. 打开“后续研究”。解析未完成会显示等待，页面每2秒更新待解析记录；可以关闭后再回来。解析失败时不能创建任务，按提示重新解析后需要重新核对并建立新版本的交接。
5. 点击“以此全文新建研究任务”。该来源预选并固定，模型默认关闭，默认输出为原文证据。可以补充问题、选择其他文献对比或调整输出；先生成计划、核对来源，再开始执行。点击“取消交接，改为普通任务”可以退出该固定来源约束。

获取PDF是一次独立的明确操作，不使用原发现任务的书目请求额度；交接记录的重新打开和新建任务不会再次下载或检索。已有全文时可优先本地关联。新任务仍受原有工具、时间、模型与元数据预算限制，图表/译文等需要各自明确参数。

## 固定哪些内容

交接保存书目原快照、可选检索ID/原任务ID、文档ID、文件SHA-256和ParseRun。来源已删除、文件变化、解析缺失/失败或没有可检索内容时阻止创建任务；在后续步骤开始前仍校验绑定文件和交接快照。

文献重新解析后，已有交接继续使用当时已完成的历史ParseRun，不自动跟随新版本。若希望使用新解析结果，请重新核对关联。新任务选择多个同作品版本时，交接的确切文档优先，不能被较新版本静默替换。段落翻译选择器也读取已绑定解析版本。

书目不加入原文证据。原研究任务的来源、预算、状态和结果不会被新任务修改；新任务可以有独立来源和预算，但不继承原任务的模型许可。程序核对文件/引用锚点不能代替论点支持和翻译质量核验。

## 保存与导出

“后续研究”保留最近40条交接。相同快照、文件和解析版本的重复确认复用记录；不同书目快照/文件/解析版本另存。来源删除后旧交接明确不可用，不能用残留书目替代全文。

新任务JSON保存完整 `handoff`，Markdown列出交接来源；ZIP另含 `handoff.json`，可回查原任务、检索快照、书目来源和确切文件。模型默认关闭时产物仍是原文候选/计划，不是已核验答案。

本轮本机实测使用既有官方BERT全文及已保存Crossref快照，真实新增下载、书目联网和模型请求均为0。下载→解析→后续任务路径另用明确虚构的元数据与隔离PDF模拟验证；没有把该模拟描述成真实外网下载成功。

0.26.0已增加已核对书目的批量全文队列，每篇沿用本说明的固定版本交接与新任务规则，见[批量操作](LITERATURE_BATCHES.md)。真实PDF获取命中已有哈希复用、纯本地队列与后续证据任务见[阶段42](STAGE42_TEST_REPORT.md)。
