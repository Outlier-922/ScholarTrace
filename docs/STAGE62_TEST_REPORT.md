# 跨论文结构与训练条件比较修复

日期：2026-11-14。仅完善产品功能，展示发布事项仍由用户后续处理。

## 问题及修复

官方 Transformer 与 LayerNorm 论文比较题，首次回答只有结构位置，遗漏训练稳定性和 warmup，且没有显示遗漏。新增三个独立字段：归一化位置及残差顺序、训练稳定性及分析范围、warmup 设置及适用条件。论文英文标题中的 Architecture 不再自动挤占具体位置问题。

进一步实测发现：字段补检索虽找到直接证据，最终证据选择仍让泛背景挤掉它。现为每篇、每个字段优先保留相关段落，再按字段相关度填充剩余位置，最后补入至多一个连续原段。原有证据 ID、解析版本与页面坐标保持原样；最终证据数及最多 12 次本地补检索预算不增加。提示词要求区分初始化理论与具体实验，不把某设置免 warmup 推广到所有模型。

## 实测

开发验证共 6 次真实模型请求：首次两题、两轮各一次定位修复、最终两题。每次沿用 1600 输出 token 上限；预期事实不发给模型，首次和中间失败输出均保留在 output/stage62。不是独立盲测或准确率估计。

- 最终 LayerNorm 比较：原始 Transformer 的 `LayerNorm(x + Sublayer(x))`、4000 warmup steps，均由该论文直接证据支持；Post-LN 与 Pre-LN 顺序来自另一篇对应原段，未将 Pre-LN 当成原始默认结构。
- 初始化平均场分析的梯度结论由第 1 页段落及第 2 页续段支持；BERT base 的 10k warmup、不同学习率及发散结果分别由实验段支持，没有推广成任意设置都可免 warmup。
- 原始 Transformer 的训练稳定性字段仍标为当前证据不足，不借用另一篇结论填充。
- BERT/Transformer 题保留编码器、编码器—解码器注意力和双向上下文的证据。最终回答没有直接展开“BERT是否含生成式解码器”这一否定子问，说明复杂架构字段内部的完整性仍需继续改善；不据此宣称全部多文推理通过。
- 28 道既有检索回归：33/33 预期证据组、168/168 原文锚点有效，零模型调用。只证明此开发集检索与定位，不能当作生成正确率。
- 浏览器恢复已保存问答并点击 warmup 引用：跳转 PDF 第 7 页、原段高亮成功，无新增模型请求。
