# 双栏扫描页公式定位验收

2026-11-16。将赛题资料中的 RWKV（`2305.13048v2.pdf`）和 *On Layer Normalization in the Transformer Architecture*（`2002.04745v2.pdf`）各前四页制作成验收用的纯图像副本，使用作品的日常 OCR、公式候选和裁图入口。公式内容与原 PDF 对照，解析和裁图定位绑定到验收副本。

|---|---|

| RWKV 第 4 页 | 左栏 (14)–(16)，右栏 (17)–(18)。第 (16) 式完整保留两侧末项与分母，位于公式下方的编号在裁图外 |

| LayerNorm 第 4 页 | 表格与图例中的表达式未进入独立公式列表 |

22 个位置均核对栏归属和裁图来源摘要。在浏览器中分别点击 RWKV 第 3 页左栏 (8) 和右栏 (11)，两处都跳回对应栏。原 Transformer 单栏样卷的 8 个选区坐标逐一复验一致。

抽查 5 个位置的本机 LaTeX 结果。放开安全数学子集中的逐元素乘号后，RWKV (11) 通过源码检查，并可用 KaTeX 渲染。RWKV (4) 和 LayerNorm (1) 的识别稿可保存，但分别出现重音误读和多余竖线，已对照原图另存修订。RWKV (8)、(16) 的识别稿未通过检查，原图保留，在验收库照原图录入并核对带来源的 TeX 导出。
