# 首页作者与机构的原文定位

2026-11-09，应用 0.37.0。打开文献后选择「目录 → 作者与机构」。姓名、署名机构及工作期间脚注分别定位到所选解析记录的首页原文块。接口返回块内字符起止位置，原文定位高亮对应文本块。

## 提取范围

在原生首页找到标题后，限定到标题与摘要之间的署名区。支持带联系行的同块署名、同列相邻块、同一联系组内的共同机构，以及联系名单上的编号与明确机构释义。可核对的工作期间脚注单列。邮箱只用于划分联系组，机构依据来自原文文字。

当前支持的布局需要可定位的首页标题和明确联系组。CLIP 和 LayerNorm 的无邮箱编号长署名行、扫描版和教材封面仍需各自的版式规则。
