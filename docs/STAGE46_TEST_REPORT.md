日期2026-11-06；应用0.30.0。此轮补齐已有筛选记录在后续操作中丢失的说明与核验链，不新增自动科研结论。

## 变更

从筛选快照关联或获取全文时，交接记录新增该候选的采用依据：研究目标、用途、理由、引用原句、引用源论文与ParseRun、原页块及筛选快照摘要。仅复制本候选的决定，不把其他排除或待查项带成任务来源。普通检索建立的旧交接继续按原逻辑使用。

筛选采用范围与原句位置在关联/获取前校验，保存交接时再校验；规划新任务和每步执行前沿用既有交接校验。筛选快照变化、源论文删除、原文件缺失/哈希变化、引用位置不一致时，交接显示“采用依据不可用”，要求重新核对；不会静默切换到新用途。已经存在的候选全文仍在库，受限的是依赖失效筛选依据的这条交接。

“后续研究”卡片及新任务预览显示“为何采用此文献”，可以回到引用源论文的原页。任务JSON与ZIP中的handoff.json保留完整采用依据；写作草稿JSON保留交接，Markdown新增单独的采用依据区。

采用依据来自引用源论文，是读者选择此候选的背景，不能替代候选论文的事实证据。此轮没有把源论文自动加入任务sources或写作evidence，也没有把采用理由当作实验结论或模型事实。
