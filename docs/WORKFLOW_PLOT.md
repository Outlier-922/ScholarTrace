# 在研究任务中绘制 CSV 科研图表

版本0.22.0。此功能复用原科学绘图的六种固定模板，将数据规则、执行检查点和复现文件放入同一研究任务。[实际记录](STAGE26_TEST_REPORT.md)。

## 操作

1. 打开“研究任务”，写明“根据 CSV 绘制柱状图”等意图；或手动勾选“CSV 科研图表”。仍需选择至少一篇本地文献作为研究上下文，CSV不自动成为论文原文证据。
2. 在任务内导入CSV（最多2MB、10000条记录），或选择已有数据。没有实验数据时可加载“任务自建演示 CSV”，其数值完全虚构。
3. 选择模板、横轴和指标；明确分组、重复标识、聚合、缺失处理、误差条及单位。雷达图逐项选择方向和归一化方式；需要时填写边界。
4. 点击“生成执行计划”。后端先校验数据哈希、列和统计规则，再显示实际使用与排除记录；无效配置不会先调用规划模型。展开完整规则和计算图注核对后，再点击“开始执行”。
5. 在“绘制 CSV 科研图表”步骤查看图、图注和下载链接。上方“导出任务包”包含图表及完整复现文件；也能在“写作与绘图→CSV 科学绘图→图表历史”打开产物。

## 固定规则和预算

计划保存数据ID、CSV SHA-256、数据状态、完整ChartSpec、绘图运行时指纹和计算预览。执行前后检查CSV；版本或数据变化后需重新规划，不会静默切换数据。模板的统计过程、缺失行序号、均值/SD/SEM、单位和归一化边界都来自明确规则。缺失默认报告停止，不插补；不默认猜测重复实验、方向、单位或因果。

绘图计一次高层工具调用，不需要模型或书目联网额度。纯绘图任务的原文检索及补检索也不会额外生成模型问答。与写作等工具组合时，其他步骤仍遵循该任务的模型开关与预算。默认模型开关关闭。

工具或活动时间预算耗尽时保留已完成步骤，显式调整后继续；暂停/取消在步骤边界生效，不硬中断当前绘图。中断后用任务内确定的产物ID恢复已注册图表，原文步骤不重做。活动时间上限仍为软边界。未知绘图异常停止，不能自动改规则来取得一张图。

## 复现包

任务ZIP的 `plot/` 中有：`input.csv`、`processed.csv`、`manifest.json`、`result.json`、`result.md`、`caption.txt`、`figure.png/svg/pdf`、`render.py`、`requirements.txt`、`README.txt`。`result.json`记录每个复现文件的SHA-256；导出前若文件变动/缺失返回409，避免不一致包。已有独立科学绘图包格式保持原样。

解压后在有记录依赖的Python环境运行 `python plot/render.py`，在 `plot/reproduced/` 生成图表和处理后数据，不覆盖原产物。输入CSV哈希变化时拒绝重画。字体或绘图库差异可能改变外观，不承诺PNG/PDF逐字节一致；本轮核对的是处理后CSV和图注字节一致。

## 通过范围

已验证六类模板在任务内调用、预算恢复、异常阻断、中断产物复用、文件完整性及三条本机路径。数据为自建演示，不是论文实验结果；绘图不证明数据真实性、实验独立性、显著性或学术结论。有限意图规则识别绘图关键词，不是自由执行分析代码，也不代表所有科研意图已闭环。
