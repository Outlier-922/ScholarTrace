# 版本用例和批量引用图谱验收

2026-11-10，应用 0.38.0。以赛道 10040 模块一、验证用例 3.1 和模块五为验收依据。完成状态按具体场景和可核对的结果判断。[赛题官网](https://www.boxuegu.com/matchTrack/detail/?id=10040)

## M1-VERSION · 通过

在新建的隔离文献库，用独立 Chrome 先上传官方 Transformer v7，再上传改名后的 v1。重复提示与新版建议正确显示。选择保留后，全库问答使用 v7。以 v1 覆盖默认后，全库问答改用 v1，刷新后仍有效，手动指定 v7 仍可引用 v7。两个 PDF 的哈希均与官方输入相同，先前 v7 第 5 页的原文锚点仍可回查。覆盖的范围是全库问答默认版本。

两版文本差异和定位已逐条抽查。曾用 37 份官方 PDF 验证无首页编号时的内容归组，Transformer 与 Emergent 的同作文件分别成组。大幅改写及低质量 OCR 样本是该用例之外的适用范围。[差异记录](STAGE51_TEST_REPORT.md) · [无编号样本](STAGE52_TEST_REPORT.md)

## M5-GRAPH · 通过

以原 20 篇、680 页的官方样本和固定解析记录重新构图。得到 150 个节点、295 条边，128 条边可参与指标计算，其中 62 条为所选本地全文之间的边。模型与注册网络请求均为 0。

在图谱中新增「基石与边缘衍生论文候选」。基石候选至少被两篇所选本地论文引用，按子图 PageRank 排序。边缘衍生候选至多被一篇所选本地论文引用，并直接引用一个或多个入选基石。每组最多显示 5 项。两组名单均由原图中可计算的本地边重新核对。边缘候选列出的关系可直接展开引用依据。[图谱回算](../output/stage58/graph-validation.json)

在浏览器中打开同批 20 篇论文的历史图谱，选择 LayerNorm 的边缘衍生候选，打开它对 Transformer 的引用依据，成功跳到 LayerNorm 第 10 页并高亮对应书目块。角色标签表示当前样本的图拓扑，学术承袭关系仍要结合正文理解。综述质量和未来方向排除作为模块五的独立要求继续验收。

49 项相关测试、780 项全量回归及 TypeScript/Vite 构建通过。两项验收状态写入项目清单，正式交付校验仍有 12 项功能和 5 项交付待完成。[总验收表](ACCEPTANCE.md)
