# 产品剩余工作与完成条件

更新：2026-11-15。依据当前验收记录整理；以下是项目收尾任务，不新增主办方要求。展示发布材料由用户后续处理。

| 工作包 | 当前真正的缺口 | 关闭条件 |
|---|---|---|
| 解析与公式 | 扫描署名/表格、复杂图表结构尚未全面验收；扫描公式仍主要依赖原图与手工修订 | 用官方代表性原生/扫描样本核验结构与公式，错误、未支持项与原图定位明确，必要抽取能力落实 |
| 阅读与翻译 | 已修复明确两页续句案例；复杂版式、其他跨块关系、全文译文质量和完整对齐尚未验收；局部选区仍需扩大验证 | 固定代表性单文全文与选区任务，核对漏译、重复、术语、数值、否定、对应位置和中断恢复，关闭已知关键错误 |
| 发现与推荐 | 搜索/获取/下钻已有，引用价值筛选与追踪推荐的实际质量未验收 | 固定主题验证候选真实可查、采用理由有出处、反馈和追踪确实改变结果，失败不伪装成功 |
| 综述与方向核对 | 综述仍有论断范围和引文不充分；旧idea是否被后续研究解决缺少有效验证案例 | 新综述逐项核对来源及适用范围；方向核对用双边证据区分已解决、部分解决和证据不足 |
| 学术写作 | 可生成框架并绑定真实书目，但曾有来源错绑与外推，学术质量未验收 | 用新的写作任务检查框架、主张与参考文献，严格区分已发表结果、研究假设和待实施计划 |
| 问答与自主任务 | 多类漏答已修复、模型选工具可运行；复杂问题与研究目标的完整结果仍需集中验收 | 固定几类完整科研任务验证选工具、跨模块传递、预算、失败恢复、来源核对和最终结果；以实际完成情况更新验收表 |

完成口径：必要能力落实、上述代表性任务通过可复查验收、已知关键错误关闭，随后冻结功能。测试数量、版本号和阶段报告数量不作为完成比例。

本轮明确关闭的是“已识别的两页续句被强行分开翻译，导致角色关系误译”这一具体失败；不是整个翻译模块一次通过。后续按工作包推进，避免长期只修同一类零散问答案例。
