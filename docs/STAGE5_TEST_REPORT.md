# 第五阶段实测记录（0.5.0）

日期：2026-10-27，北京时间。本阶段完成本机引用网络、局部指标和综述证据提纲，没有配置或调用生成模型，也没有部署公网服务。

## 本轮交付

1. 从用户选择的 PDF 与具体 ParseRun 提取参考文献，拼接书目续行，保留每个原始块的坐标、页码和文本。只以书目中的 DOI/arXiv 字面标识符建边，不以主题相似度建边。
2. 批量向 arXiv 注册源核对标识符，少量 DOI 使用 Crossref 精确查询；沿用前阶段节流与缓存。返回的非请求标识符不被接受。标识符存在但书目标题和首位作者明显冲突时，边标为冲突并退出指标计算。
3. 同作品只选一个版本。已验证 Transformer v1/v7 与原生/扫描文件不重复计数，可显式切换版本重建图谱。图谱、元数据副本、源文件与解析版本形成保存时快照，重解析后不漂移；来源删除则失效。
4. SVG 交互网络、选中节点一跳、用途筛选、平移缩放、注册源链接、发表年份视图、入度/出度、局部 PageRank 与共同被引作品。引用用途由用户标注并明确保存为 `user_labeled`，不是自动核验结果。
5. 点击引用边查看原书目、分段原文及可识别的正文数字引用位置，直接回跳到阅读器对应历史解析。
   OCR 来源与识别分数继续随锚点保留，不把它们替换成原生文字或事实置信度。
6. 基于本地全文的综述证据提纲、未来工作原文、候选检索、检查记录与 JSON/Markdown 导出。未生成学术综述、创新结论或“已解决”判定。

## 图谱计算口径

- 箭头为引用者 → 被引用者，PageRank 使用入链、阻尼系数 0.85、均匀悬挂节点再分配、幂迭代收敛。每个来源作品/目标作品对只计一条边，不按重复提及数加权。
- 自环、未核对标识符及身份冲突边不进入局部指标。未核对节点没有 PageRank 值。只在当前所选、已对应子图上计算，不称为全球影响力或论文质量分数。
- 视图筛选不删除底层引用边，也不改变保存快照的指标。共同被引表示至少两个来源引用同一目标，不说明研究路线的因果关系。
- 年份视图使用注册源首次发表年；未知年份保留“未核对”，不拿上传日期补齐。年份先后不等于方法继承关系。

方法依据：[PageRank 官方算法文档](https://networkx.org/documentation/stable/reference/algorithms/generated/networkx.algorithms.link_analysis.pagerank_alg.pagerank.html)、[arXiv 批量标识符 API](https://info.arxiv.org/help/api/user-manual.html)。本实现使用小图的纯 Python 幂迭代，没有新增 NetworkX 运行时依赖。

## 修复与边界

- 原解析的书目数组会包含部分续行、页内生成表格块或附录文本。本模块过滤生成块、约束书目结束边界；多标识符候选不强配。仍未保证作者年份书目完全分条或自动消歧，因此保留较多待解析片段。
- 作品分组沿用明确 arXiv 根标识符和当前文献库作品分组。非 arXiv 内容重合候选、DOI/arXiv 跨源同一作品识别仍需进一步核对，不宣称已解决通用实体归并。
- Future Work 提取是关键词与原始块的可审查基线，能跨 PDF 换行，但不是完整语义识别。候选粗筛使用首次发表年，不能证明晚于原方向所在的具体修订版。
- 图谱默认最多 100 节点，接口上限 150；注册核对有预算，超出预算保留原书目。只展开直接引用，尚未递归展开外部论文、全文阅读或进行系统性综述。
- 概念相似边、自动用途分类、完整语义综述、后续工作的全文解决程度核验、公网鉴权和多用户隔离仍未完成。真实生成模型问答/翻译质量也仍待本机密钥配置。

```powershell
.venv312/Scripts/python.exe -m pytest -q
.venv312/Scripts/python.exe scripts/dev.py
# 另开终端；默认只复用已有注册记录
.venv312/Scripts/python.exe -X utf8 scripts/verify_stage5.py

.venv312/Scripts/python.exe -X utf8 scripts/verify_stage5.py --resolve-metadata
```
