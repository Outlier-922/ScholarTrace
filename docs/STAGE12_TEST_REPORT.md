## 离线工具约束

生成器拒绝题目/响应哈希漂移、重复或空运行，拒绝覆盖输出；默认全部pending。页面使用textContent呈现文本，嵌入JSON转义尖括号等字符；CSP只允许固定脚本/样式哈希，禁止网络连接。没有API、数据库或模型密钥依赖。

页面展示问题、原始保留回答、标准事实草稿、缺失说明、陈述引用、候选原文、页码和块坐标，另列保存的版式候选；仍需核对原PDF。人工填写身份、标准事实核对、完整回答判定和依据后勾选；必要信息不齐时继续pending。支持条数可留空，CLI的语义支持指标因此保留null。JSON导入核对同一题目和响应哈希，不接收其他运行替换。

这些机制只帮助保存与核对记录，不能证明填写人独立，也不能验证人工判断真实或正确。真实六题仍0/6独立复核；本阶段未代填科研答案质量。
