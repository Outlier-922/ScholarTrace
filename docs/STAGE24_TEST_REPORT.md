# 必要能力收尾：任务内段落翻译（0.20.0）

客户端日期：2026-10-29。工作包2，补齐研究任务与既有阅读翻译接口的连接。当前版本0.20.0，不因测试数量升版。

## 实际变化

新增第七种白名单工具`translation`。用户明确选择1—4个正文块、原解析版本、页码、目标语言与可选术语表；服务端在任何规划模型请求前校验范围，不允许模型猜测待译全文或扩大来源。每段展开为独立步骤，沿用统一模型预算、段落边界暂停/恢复和原文失效检查。

执行复用既有`translation-v1`保护和缓存，未改翻译生成提示。纯翻译计划不额外生成问答；预算不足保留待执行段落；已捕获的模型失败按有界策略保存原失败与无译文的本地替代。UI新增本地逐页选段、有效术语校验、执行前完整原文预览、原译对照、缓存/未译状态和原页回跳。任务ZIP增加逐段Markdown/JSON。写作仍从原论文证据生成固定框架，不声称自动理解译文写成论文。

## 原译核对与边界

开发助手逐句对照：原段中迁移学习兴起、NLP中的预训练模型应用、数亿参数、更大模型与下游性能四部分均有对应；术语按显式映射保留，三个作者年份与NLP缩写未增加或删除。数字/占位符检查通过，未观察到该段新增数据或结论。

这不是独立人工复核、留出数据或准确率统计。源段的脚注上标已在普通文本中并为`research1`，译文保留“研究1”；当前不重排脚注，必须看原PDF。数值保护和单段对照不能证明长书译文、跨段长句、专有术语、公式或学术语义全面正确，`semantic_verified=false`保留。
