# 基于引用位置的显式用途筛选

日期2026-11-06，应用0.29.0。本轮实现读者对候选的研究用途判断与入库范围交接，不宣称自动完成引用价值评估。

## 操作与行为

从阅读器引用页展开候选后，在发现结果打开“对照正文，筛选本研究要采用的候选”。填写具体研究目标，为每个候选分别记录身份是否对应、采用/排除/待查、方法/数据/比较/背景用途和理由。

服务端从被固定的原文件及ParseRun重新取得书目与正文引用位置，复用数字标记及作者年份标记解析。采用项需明确确认身份、选择用途，并附带此书目关联的原句；该连续片段须在原块中唯一出现，且覆盖实际引用标记。伪造文字、其他书目的位置、没有标记的片段、漏项或重复候选不能通过。只有原句位置合法不等于其语义证明用途，仍是读者判断。

位置可能来自段落、图表，界面显示原文块类型。未解析到位置时保留待查或排除，不把缺失位置视为论文无价值。采用、排除、待查均需具体理由；排除身份不对应的候选时不强制捏造正文证据。

筛选另存为新发现快照，只有采用项进入其items，原候选和所有决定保留在screening轨迹，绑定原快照摘要。既有入库和本地关联接口按新快照检查候选，排除/待查项即使直接请求接口也不能以此快照入库。原快照仍完整可用；这是明确范围的筛选，不是全局禁止某篇论文。

可以导出完整筛选JSON，从原快照打开最近20条筛选历史，或从筛选轨迹返回原候选另存新判断。原记录不覆盖，筛选结果不嵌套改写。所有新判断均不调用模型或外网。

## 剩余工作

当前是可追溯的显式读者筛选，自动引用价值判断、科研质量和更深层扩展仍未验收。原文位置可能解析不全，引用片段也可能缺少上下文；本功能不能自动确认候选论文的全文结论、创新性或实验可复现性。M4-DISCOVERY继续部分实现，整体正式参赛交付未完成。
