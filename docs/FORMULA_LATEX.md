# 公式候选、原图与修订

入口为文献与阅读 → 打开论文 → 选择页码 → **公式**。

## 从扫描页识别

1. 勾选“框选原页公式”，在页面图像上拖动，选中一条公式。框内保留分子、分母、根号和上下标，避开编号及旁边正文。
2. 点击“保存选区并预览裁图”，核对裁图后点“识别扫描公式”。识别使用裁图和本机 OCR，不需要模型 API。相同选区与识别模型可复用已有候选。
3. 对照裁图检查源码和预览。可修改后另存手工修订，并从历史打开原识别稿。点击“在原页定位选区”会高亮原图中的矩形。TeX 导出保留文件摘要、解析版本、页码、选区和裁图摘要。

当前开发环境已准备本地模型。若在另一台机器安装，请在 Python 3.12 和可用的 `uv` 环境内运行以下命令。首次准备会下载约 179 MB 模型权重及独立环境所需依赖，识别时只读取本地文件。

```powershell
.venv312/Scripts/python.exe scripts/prepare_formula_ocr.py
```

## 从原生文字块转写

1. 勾选同页1—6个内容块。公式常被拆成分子、分母、结尾等多个块；用“显示本页其他内容块”补选漏掉的部分。
2. 点击“查看所选原图与字形”，先核对裁剪范围。此步不调用模型。模型不会收到原图。
3. 有原生字形时可点击“生成 LaTeX 候选”，最多一次模型请求，1600输出预留token。相同来源、模型配置身份与提示版本在保留历史范围内可复用。
4. 将源码和渲染结果对照原图，逐个检查符号、上下标、分数和根号的范围。能渲染不代表数学正确。
5. 修改源码，填写修订说明，点击“另存手工修订”。旧稿保留，历史可以重新打开；手工稿也不会自动变成“已核验”。
6. “原页核对 · 源块N”回到相应内容块；多块来源逐块核对。导出的TeX片段包含文件SHA256、解析版本、页码、各块与坐标。

切页或关闭页面只停止本页等待，不保证取消已发出的模型请求。

扫描或 OCR 文本提供的符号位置不足以走原生字形转写。此时可切到框选方式，也可对照原图手工录入。

每个来源固定文件、解析版本和内容块或矩形选区。重新解析保留旧来源，删除文献后相关公式与裁剪失效。模型和手工结果分别保存。原生文字超过 2200 字符、字形超过 800 个时需要缩小选择。扫描框选限定同页，过小或接近整页的范围需调整。

源码限制为4000字符的数学子集。服务端检查命令、括号与环境，**不完整解析TeX，也不证明数学等价**；直接通过API保存的结构合法片段仍可能渲染失败。页面用本地打包的KaTeX 0.19.1解析，错误以文本显示，并在预览失败时禁用手工保存。配置为`trust:false`、`maxSize:8`、`maxExpand:100`，每次使用新宏表；参见[KaTeX安全文档](https://katex.org/docs/security.html)和[渲染选项](https://katex.org/docs/options.html)。

跨页、旋转页、整页公式自动定位与复杂公式准确率仍待验收。官方扫描件的已核对样例见[扫描公式实测](STAGE67_TEST_REPORT.md)。
