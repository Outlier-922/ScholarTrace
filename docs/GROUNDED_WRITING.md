# 依据原文生成学术研究计划

“创建写作框架”在本地运行。选“生成草稿并复核引用”后，系统调用模型起草，并逐段对照引句。研究任务的写作步骤使用本地框架。

## 操作步骤

1. 在“写作与绘图”选择文献或已有图谱，写清研究想法，创建框架。先保存所有编辑。
2. 核对框架的证据、原文页码及书目身份；没有正文证据时不能起草。已保存框架固定来源和ParseRun，后续不会自动扩展来源。
3. 填“学术草稿写作要求”，点击“生成草稿并复核引用”。起草最多读取已保存的前 8 条证据，每条至多 1600 字符，合计上限 10000 字符。起草和复核各最多发出一次请求，各预留 2400 个输出 token。
4. 六节包含摘要、引言、相关工作、方法、实验和局限。事实转述必须绑定一条证据和连续原文引句；数字依据该引句检查，不能靠整段其他数字蒙混通过。方法、实验和摘要为待实施计划，不能宣称已获得结果。
5. 结构、引句和数字检查通过后，复核模型逐段查看转述及对应引句。获得完整支持建议的转述进入草稿，其余段落保留原文摘录。生成记录保存原候选与复核意见。点击页码核对原文、语境和实验条件。已确认注册身份的书目进入 References。
6. 如果未通过，原稿不变；展开“生成记录”查看原始候选、拒绝原因及实际用量。传输/JSON解析失败只能保留状态和已记录用量，不能保证有完整候选。中断后重新打开历史，不自动重试；服务重启将未完成请求标为中断。
7. 点击“载入候选供校订·不调用模型”，在编辑区修改转述、来源和核验引句，填写校订说明，保存新版本。这条路径重新检查相同原文快照和全部事实/计划，0模型请求；原始候选、原拒绝原因不覆盖。若已产生并发新版本，保存会拒绝覆盖。未匹配的来源需重新选择，不能强行沿用外部ID。

“保存新版本”在普通编辑状态使用原有段落规则；在候选校订状态使用更严格的六节起草规则。改变引句、文本或来源后仍需核对语义；删除引句不是语义通过的办法。一次草稿同时仅允许一个生成请求，同一请求ID重放不重复调用。
