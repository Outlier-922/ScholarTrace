## 结论与限制

M1-FORMULA从missing调整为partial。只支持原生字形转写候选和手工路径；公式线索会漏检/误检，分母和结尾要人工补选。原生向量线条未单独建模，旋转/跨页/自由框选和公式OCR尚未实现。服务端只验证TeX结构子集，预览能否渲染和数学等价是不同判断。两个已知论文样本不足以推断其他公式质量。

总验收仍有20项必要项未通过；公网、最终版技术PDF、MP4、评审仓库访问与用户要求暂缓的身份信息仍待完成。历史0.9.0技术PDF本轮未覆盖或更新。
