# 必要能力收尾：研究任务反馈恢复（0.19.0）

## 实现与冻结

新增`bounded-feedback-v1`策略：保存计划版本，识别证据生成失败，保留候选原文和原失败步骤，插入本地替代并重接依赖。检索补充与模型降级共同受0—3次调整上限约束。未知工具错误、来源失效和依赖未满足仍停止；原来源和预算固定。恢复后不重发原模型请求，后续模型关闭。UI增加恢复策略、调整上限、计划历史、失败替代入口，以及模拟记录标识；任务ZIP增加计划历史。

手动输出跳过额外模型规划；有限规则能识别的必要动作/维度不会被模型省略，明确否定动作不会被模型建议重新打开。原文验证补查页码并按文献/解析版本复用结构，避免反复加载长书。

运行前保存[44文件及两篇原文快照](../evaluation/freeze_stage23_workflow_feedback_v1.json)，指纹按UTF-8统一换行计算。此前Git基线为`ad4b9ce`。未为本轮修改问答、比较或综述生成提示；比较增加结构化模型失败信息供执行器读取。首轮结果保留；末次复核发现恢复后补检索读取失败步骤的漏洞，随后另存45文件的v2快照并重新执行，详见下节。生成提示始终未改变。
