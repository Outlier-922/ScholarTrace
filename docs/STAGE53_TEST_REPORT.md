# 保留现有版本或覆盖默认版本

2026-11-09，应用 0.36.0。上传文件归入已有作品后，阅读区显示同作提醒、可读版本建议和「保留或覆盖版本」入口。

- 「保留现有默认版本」保存面板所列的现有版本。首次选择以库中已有可读稿为起点。
- 「以当前文件覆盖默认版本」把当前文件设为该作品的全库问答默认。默认选择写入 SQLite，用户可以从版本菜单切换后再选择。
- 全库问答按保存的默认选择文献。单文问答、手动勾选的文献和显式固定的解析记录继续按具体文件取证。原始 PDF、解析记录、版本对照和历史问答都可按对应文件访问。

## 官方用例

在隔离工作区使用独立 Chrome，从上传入口先导入 Transformer v7，再以 `opaque-upload.pdf` 的文件名导入官方 v1。界面提示检测到同一作品的多个文件，并推荐 v7。两次选择都在界面点击完成。

| 检查 | 实际结果 |
|---|---|
| 保留现有默认后执行全库问答 | 来源范围为 v7 |
| 以 v1 覆盖默认后执行全库问答 | 来源范围为 v1，重载页面后仍显示默认 v1 |
| 阅读区打开 v7，再从全库范围提交问题 | 点击返回的证据跳到 v1 |
| 明确指定 v7 提问 | 来源范围为 v7 |
| 回查覆盖前的保存问答 | v7 第 5 页的引用仍能解析到当时的块 ID |
| 下载两版原 PDF 并计算 SHA-256 | 两份都与官方输入一致 |

这些检查调用模型 0 次。相关回归覆盖重复提交、过期选择被拒绝、只读模式、手动固定旧解析、删除默认文件后的回退。首次全量运行发现共享测试库中其他用例留下的无效解析记录干扰了隐式检索用例。隔离该测试的文献范围后，全量 776 项测试通过，TypeScript 检查和 Vite 构建通过。

此处的覆盖是替换全库问答默认。内容归组对大幅改写和低质量 OCR 的适用范围仍待验收。
