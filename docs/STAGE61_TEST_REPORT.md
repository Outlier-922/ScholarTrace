# 0.41.0 多问句漏答与跨文条件修复

日期2026-11-12。本轮只改善作品能力。展示、仓库上传、视频、最终PDF与公网发布按用户要求交由其后续处理，不计入产品未完成条件，见[当前产品范围](PRODUCT_SCOPE.md)。

## 复现的问题

在同一批官方PDF与确切解析版本上，首次真实模型运行3题：

1. Transformer层数、输出维度、注意力头数三问，系统只识别层数字段，答案漏掉头数，且没有报告该遗漏。
2. 早期GPT论文与GPT-3的参数量、上下文比较只识别上下文字段；GPT-3正确的2048回答因名称中的“3”未出现在所引片段而被数字校验拒绝。早期GPT的512训练序列原段未返回。
3. Transformer层数与指定任务BLEU二问只识别层数；检索被另一问题的WMT/BLEU词项主导，最终没有回答任何一项。

首次输出原样保留，没有将修复后结果当作首次结果。

## 改动

新增参数量、隐藏/输出维度、注意力头数、BLEU字段。补检索仅保留对应子句的关键词，同时保留章节与训练阶段限制。明确数值字段在最多30条本地候选内优先选择有量值陈述的原段；最终证据数量及最多12次字段补检索上限不变，不增加模型调用。不以论文名称、页码、预期答案或块ID编写检索分支。

模型名称数字必须有同篇原文中的完整名称佐证，且该佐证加入显示的引用。只豁免名称内部对应字符，不把同一个数字放宽为层数、参数量等普通量值；伪造名称或借用别篇名称仍拦截。

上下文回答明确区分“训练使用的序列长度”与“架构最大容量”。参数量回答不附加未被问到的模型个数，避免把某项评测子集说成全部模型。

第一次修复后，512原段已经找到，但模型仍将长度整体报缺失；补充条件说明后得到完整候选。随后发现候选把文章生成评测中的“四个模型”附带到总体参数量描述，限定参数字段输出后复验去除了该无关数量。全部中间结果保留，不以重复采样挑选答案。

本轮共8次真实问答请求，单次上限1600输出token。成功的结构与BLEU答案又使用最终代码本地重验，0新增模型请求。首次被拒绝的GPT-3原候选也单独重验，通过补充同篇原文名称出处恢复2048回答，证明不是依靠重新生成碰巧绕过问题。对照原文核对属于开发助手复核，不是独立专家盲评，系统仍保持 `semantic_verified=false`。

既有28道开发回归题使用最终代码、关闭生成重跑，33/33指定证据组命中，168/168锚点有效，0请求错误。它证明既有证据召回没有观察到退化，不等于问答准确率100%。
